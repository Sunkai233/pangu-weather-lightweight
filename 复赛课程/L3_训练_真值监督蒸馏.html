读导读:这一课要回答的问题↑

蒸馏 = 让小学生(学生模型)模仿大老师(教师 Pangu)的输出。但有个天花板:学生再像老师,也只能逼近老师,永远超不过老师。而 W 的打分公式里,学生 RMSE 比教师小才拿高分。怎么突破?除了模仿老师,还让学生直接看"标准答案"(ERA5 真值)——这就是真值监督。distill_truth.py 就是把"模仿老师"和"对答案"两种监督混在一起训。

一句话抓住这一课

损失 = α·(对教师的蒸馏损失) + (1−α)·(对真值的损失)。非温度通道纯蒸馏(老师已经很准),温度等"学生退化明显"的通道掺真值(让它超过老师)。再配上选优看真值、resume 续训、谱损失补细节,就训出了 bo3b。

数字为用户实测。W 的两跳(+0.39)都来自本课的训练改进。教师对真值的温度 RMSE 是天花板,学生破它即超教师。

1纯蒸馏的天花板(为什么要真值监督)↑

W 打分核心是 min((教师RMSE / 学生RMSE)², 1):学生 RMSE ≥ 教师时永远 < 满分。纯蒸馏让学生对齐教师输出,最好也就追平教师(比值→1),拿不到满分。要超满分线,必须让学生在某些通道比教师还准——只能靠直接学真值。

为什么挑"温度 + 低层 u/v/q"掺真值,而不是全部

分析发现学生相对教师退化最集中在近地面温度、低层风/湿(受地形、边界层影响)。这些通道误差里有大量"可降的方差"——掺真值能直接压下去、超教师。而高层 z/t 学生已追平教师(比值≈1),全掺真值反而可能把它带歪。所以是选择性真值:哪里弱补哪里。

2数据:连续 6h 真值对 + 落盘缓存↑

这段干啥:真值监督需要"输入 t → 真实未来场 t+6h"的配对。build_pairs 扫连续 ERA5 文件,只有相邻两文件时间戳恰好差 6 小时才配成一对。

distill_truth.py · L94–L104
def build_pairs(years):
    """连续文件相邻配对:(files[i], files[i+1]) = (输入t, 真值t+6h),仅当时间戳恰好差6h。"""
    pairs = []
    for y in years:
        fs = sorted(glob.glob(f"{BASE}/data/{y}/*.h5"))
        for i in range(len(fs)-1):
            t0 = datetime.strptime(os.path.basename(fs[i])[:10], "%Y%m%d%H")
            t1 = datetime.strptime(os.path.basename(fs[i+1])[:10], "%Y%m%d%H")
            if (t1-t0).total_seconds() == 6*3600:   // 恰好差6h才配对
                pairs.append((fs[i], fs[i+1]))
    return pairs

落盘缓存(DiskList):教师输出 + 真值每对存一个 .pt 文件,训练时按需从磁盘读回。这是为了规避 RAM 上限(abc66 容器 RAM 有限),从而能上全量数据;还支持 random.shuffle 就地洗路径。换 lr/超参重训时,同配置的 .pt 可复用(免重算教师),省一大笔时间。

4损失构造逐项(这一课的核心)↑

每个训练样本,学生输出 ss(地面)、su(高空)。损失由几块按需叠加。先建加权(纬度加权 coslat × 官方逐通道权重 sw/pw × 动态权重 dyn_w × 区域权重)。下面逐块拆。

4.1 非温度通道纯蒸馏 + 温度通道 α 混合

这段干啥:核心那一笔。用一个温度掩膜 tmask:非温度通道权重不动(纯对教师),温度通道把教师权重压成 (1−tmask·(1−α))、剩下的 (1−α) 留给真值项。

distill_truth.py · L487–L497
# 非温度通道:纯教师;温度通道:α 教师 + (1-α) 真值
te_w_s = wsd * (1 - tmask_s * (1 - a))      # a = truth-alpha
te_w_u = wud * (1 - tmask_u * (1 - a))
loss = wl1(ssf, ts, te_w_s, 0.25) + wl1(suf, tu, te_w_u, 1.0)   # 对教师 ts/tu
# 温度真值项(权重×(1-α)):2m_t + 温度层 对真值 trs/tru_t
if (1-a) > 0:
    w2m = wsd[:, 3:4] * (1-a)
    loss += 0.25 * (F.l1_loss(ssf[:,3:4], trs[:,3:4], reduction="none") * w2m).mean()
    wtu = wud[:, T_UPPER_IDX] * (1-a)
    loss += 1.0 * (F.l1_loss(suf[:,T_UPPER_IDX], tru_t, reduction="none") * wtu).mean()
α 怎么调

--truth-alpha 0.5 = 教师/真值各半。α=1 纯蒸馏(回到天花板),α=0 纯真值(可能丢失教师的物理一致性)。0.5 是表达力(像教师)和技能(超真值)的平衡点。冲 W 可往 0.3–0.4 偏真值,但要盯着别把别的通道带歪。

4.3 truth-full15 + full-temp(防高空漂移)

这段干啥:更激进的 --truth-full15:全 15 指标对应的所有通道都掺真值(直接学 ERA5,超 3 年前的教师)。配套 --full-temp:温度真值覆盖全部 13 层而不只近地面 3 层。为什么要 full?只监督近地面会让高空温度"漂移"——浅监督把近地面拉准、高空没人管就跑偏,净 W 反降。full 全层一起管住。

4.4 高频谱损失(治 patch16 过平滑)

这段干啥:patch16 把图压得狠,输出容易"低通过平滑"(丢小尺度)。谱损失在频域惩罚"预测 vs 真值"的高频幅度差(波数 > kmin),逼模型还原中小尺度。用 warmup 慢加权重,避免"谱损失 vs RMSE"梯度打架(谱要细节、RMSE 要平均,直接全开会冲突)。

distill_truth.py · L517–L521 + hf_spec_loss L62–L83
if args.hfspec > 0:
    hw = args.hfspec * min(1.0, (ep-start_ep+1)/max(1,args.hf_warmup))  # warmup 慢加
    loss += hw * hf_spec_loss(suf, tru, args.hf_kmin, bool(args.hf_ms))
    loss += hw * hf_spec_loss(ssf, trs, args.hf_kmin, bool(args.hf_ms)) * 0.25

4.5 protect / chanrw / DTP(防带歪 + 自动配权)

开关干啥
--protect 1.5对 u/v + 位势 + msl 的蒸馏权重 ×倍数,强化它们对教师的锚定,防温度真值训练通过共享 backbone 把它们带歪。
--chan-reweight 2.5针对性回收:低层 u/v + u10/v10 + q 上调,已追平的 t/z 降权(--tz-scale 0.8),把梯度花在弱通道。
--dtp 1(默认开)动态逐通道权重:按各通道的 L1 误差 EMA 自动调权(误差大的通道权重大),clamp(0.3,3.0) 后归一。自动版的 chanrw。
distill_truth.py · L544–L547(DTP 动态权重)
if args.dtp and ch_l1_n > 0:
    ch_l1 = ch_l1_acc / ch_l1_n

5优化器 + lr 6e-5(真值微调的关键)↑

这段干啥:分组优化:2D 权重矩阵走 Muon(lr 0.02、momentum 0.99,对 2D 权重做正交化更新),其余(embed/norm/bias/patch/logit_scale)走 AdamW。warmup + cosine 退火;EMA 0.999(评估/保存用 EMA 权重);grad clip 1.0。

distill_truth.py · L387–L400
for n,p in student.named_parameters():
    if p.ndim==2 and not any(k in n for k in ("patchembed","recovery","embed","logit_scale")):
        muon_p.append(p)        # 2D 权重 → Muon
    else: adamw_p.append(p)      # 其余 → AdamW
opt_m = Muon(muon_p, lr=args.muon_lr, momentum=args.muon_momentum)
opt_a = torch.optim.AdamW(adamw_p, lr=args.lr, weight_decay=args.wd, betas=(0.9,0.95))
★为什么真值微调用 lr 6e-5(而不是从头的 6e-4)

真值监督不是从头训,是在已有 bo 权重上 resume 微调。微调要用更低 lr(--lr 6e-5,约从头的 1/10),否则大 lr 会把已经学好的表征冲垮(尤其高层已追平教师的通道)。配合 resume,这就是"小步精修"——只把弱通道往真值方向推一点,不伤其余。记忆口诀:真值微调 = 低 lr + resume + 选优看真值。

6★选优对真值,不是对教师(bo3b 的关键改动)↑

这段干啥:每个 epoch 后选"最优 ckpt"。判优口径必须用"对真值的 RMSE",而不是 val_match(对教师的匹配度)。因为真值监督的目标就是超真值——用 val_match 选会选到"最像教师"的(即被天花板锁死的),而不是"最超真值"的。

distill_truth.py · L552–L558
# 选优口径:对【真值】越好越优,而非 val_match(对教师)。
# sel = -(对真值温度总RMSE):RMSE 越小 → sel 越大 → 存为 best。
sel = -(r2m + (sum(rup)/max(1,len(rup))))   # 2m_t + 温度层平均 RMSE
if sel > best:
    best = sel
    torch.save({"model_state_dict": ema.state_dict(), "cfg": _cfg, ...}, args.save)
    print(f"  [saved best] ... 2m_t={r2m:.3f}K")
判优铁律(决赛也适用)

真值监督一定要用真值口径选优。这正是 bo1→bo3b 的关键改动之一(+0.19)。永远盯着"和评测一致的口径"判优,别被代理指标(val_match)骗——L4 会讲怎么用 score15 把这个口径做准。

7resume 续训规则(补充训练一律 resume)↑

这段干啥:真值监督是在已有权重上续训。加数据/加 epoch/换损失的补充训练,一律从上次权重 resume,绝不从头。代码区分两种 resume:① --resume 外部权重(换数据/破天花板)→ 调度从 ep0 重跑、best 清零;② 自动续上次 ckpt → 接着 epoch/best 继续。

distill_truth.py · L369–L380
resume_from = args.resume if (args.resume and os.path.exists(args.resume)) else (ckpt_path if ...)
if resume_from:
    rk = torch.load(resume_from, map_location=...); rsd = rk["model_state_dict"]
    miss = student.load_state_dict(rsd, strict=False)
    if not args.resume == ckpt_path:    # 外部 resume → 从 ep0、best 清零
        start_ep = 0; best = -1e9
    else:                            # 自动续 → 接 epoch/best
        start_ep = rk.get("epoch",0); best = rk.get("best", -1.0)
注意:同架构才能 resume

load_state_dict(strict=False) 容忍少量键不匹配,但架构(embed/depths/heads/patch)必须一致才能 resume。换架构(升维/改层)要另起,不能 resume。物理头 --phys 是例外:新通道补 0 初始化,可在原 7 通道权重上 resume。

收小结:这一课你掌握了什么↑

  • 为什么真值监督:纯蒸馏有天花板(≤教师),掺真值才能超教师拿高 W。
  • 损失:α·教师 + (1−α)·真值;非温度纯蒸馏、温度/低层 u/v/q 掺真值(选择性);full-temp 防高空漂移;谱损失补细节;protect/chanrw/DTP 防带歪+自动配权。
  • 优化器:Muon(2D 权重)+ AdamW(其余);真值微调用 lr 6e-5(低 lr 不伤已学表征)。
  • 选优对真值:sel = −真值 RMSE,不是 val_match —— bo1→bo3b 的关键改动。
  • resume:补充训练一律 resume(同架构);外部 resume 从 ep0/best 清零,自动续接 epoch/best。
