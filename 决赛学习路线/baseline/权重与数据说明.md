# 权重与数据说明(为什么不入库 + 从哪来)

模型权重(1.87G)和 ERA5 数据(数百 GB)**太大,不放 GitHub**(单文件 100MB 上限)。本文件给出它们在赛题 DCU 容器里的位置与获取方式,配合本目录 `官方源码/` + `onescience源码/` 即可对照学习。

## 一、教师权重 model_bak.pth
- 内容:官方 Pangu 教师,**64.22M 真参数**(文件 1.87G,大头是 attn_mask buffer)。
- 容器位置:`/public/home/<你的账号>/xiandao2026-AI4S/pangu_weather/data/checkpoints/model_bak.pth`
- 下载指针:官方源码里 `data/download_model_url.txt`(赛题平台提供)。
- 用法:`inference.py` / `train.py` / `distill_scnet.py` 里 `torch.load(...)` 加载;学生蒸馏时冻结只做前向。

## 二、ERA5 数据
- 结构:`data_dir/data/{年}/{YYYYMMDDHH}.h5`(每个 h5 含 `fields` 数据集,**99 通道**)+ `stats/`(global_means/stds.npy)+ `static/`(land_mask/soil_type/topography.npy)+ `metadata.json`(99 变量名列表)。
- 容器位置:训练 `era5_real/`、测试 `era5_testc/`(均在 `/public/home/<你的账号>/`);官方共享全量在 `/work2/share/.../ERA5/old-data`(极大,只能远程访问,不能拷)。
- 归一化:`(x - global_means)/global_stds`;**按 metadata 变量名选 69 个通道**(不是取前 69,见 `学习总表` #16 通道对齐坑)。
- config 里 `conf/config.yaml` 的 `data_dir/stats_dir/static_dir` 指向数据根;`channels` 是 69 个变量名;`test_ratio` 是测试年份。

## 三、配置 conf/config.yaml(已入库,见 官方源码/conf/)
- `model`:patch_size / embed_dim / num_heads / window_size / checkpoint_dir。
- `datapipe.dataset`:69 通道 `channels` 列表、逐通道 `weights`(loss 用)、img_size(721,1440)、train/val/test 年份。
- `transforms`:Normalize 参数。
> 换机器只改 config 的三个路径 + 我们脚本的 env(PBASE/PCKPT/PDATA…)即可。
