# 决赛学习路线 · 16 单元总表 + baseline 借鉴对照

> 目标:闭卷、无大模型、**从原始模型开始**在 DCU 上把 72→69 学生模型的"建模 → 训练 → 推理 → 评测"全链路跑通。
> 本表把每个单元拆成两栏:**① 可从 baseline/成熟包直接借鉴(理解即可,不用逐字背)** 与 **② 必须自己能默写/改写的核心考点**。
> baseline 源码见同目录 `baseline/`(官方源码 + onescience 关键源码);权重/数据太大不入库,见 `baseline/权重与数据说明.md`。

## 一、三个"可借鉴"来源(不用记忆实现)

1. **成熟 PyTorch API**:`nn.Conv2d/Linear/GELU/SiLU/RMSNorm`、`F.normalize`、`F.scaled_dot_product_attention`、`F.pad`、`view/permute/reshape`、`nn.L1Loss`、`AdamW`、`CosineAnnealingLR`、`torch.fft`、`torch.inference_mode`、`.half()/.bfloat16()`。→ 查 `../docs`(如仓库带)或官方文档即可。
2. **onescience 包**(赛题容器自带,import 即用):`OneEmbedding/OneRecovery/OneSample`(= PanguEmbedding/Recovery/DownSample/UpSample)、`onescience.models.pangu.Pangu`(教师)、`onescience.datapipes.climate.ERA5Datapipe`、`onescience.utils.YParams`、`apex.optimizers.FusedAdam`。→ **这些是 stem/head/采样/数据管线,不用自己写内部**,只需会调用。
3. **baseline 现成实现**(在 `baseline/官方源码/`):`maxvit3d_student.py`(学生全部组件)、`train.py`(训练循环)、`inference.py`(推理)、`result.py`(评测)、`distill_scnet.py`(蒸馏例子)。→ 可读、可借,但下面"②考点"里的部分要能**不看也写得出**。

> 判断原则:**别人写好的成熟模块(包/API)= 借鉴**;**把它们接线成正确形状/流程的胶水 + 自定义结构 = 必须自己会**。闭卷时前者靠 import,后者靠脑子。

## 三、"必须自己默写"的最高频考点(闭卷前重点背这几样)

按重要性排:
1. **3D window partition / reverse 的 view+permute 维度**(#5)—— 最易错,`grid_reverse` 的 permute 顺序 `(0,4,1,5,2,6,3,7)` 要能推出来。
2. **72↔69 通道拆分/拼接 + 通道名对齐**(#7 #12 #16)—— surface[:7]/upper[7:].reshape(5,13);评测 99→69 按名字。
3. **QK-Norm 注意力**(#4)—— QKV reshape/permute、`F.normalize(q)`、可学习温度 `clamp(logit_scale,max=log100).exp()`。
4. **蒸馏双监督 loss + 加权 L1**(#13)—— α 权、面/高空层权、逐通道 weights。
5. **Muon 优化器**(#14)—— Newton-Schulz 五次迭代系数 `(3.4445,-4.7750,2.0315)` + Nesterov 动量 0.99,只作用 2D 骨干权重。
6. **U 形 skip 连接**(#9)—— down 前存、dec 后 concat,recovery in_chans=2·embed。
