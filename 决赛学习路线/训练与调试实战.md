## 一、6 大考点 · 最小自测(在含 `maxvit3d_student.py` 的目录跑)

### 考点 1:3D window partition/reverse —— ★可逆性是唯一验收标准
维度错一个,reverse 就恢复不了。**自测 = partition 再 reverse 必须逐元素等于原张量**:
```python
import torch
from maxvit3d_student import _pad3d, block_partition, block_reverse, grid_partition, grid_reverse
B, Pl, Lat, Lon, C = 1, 8, 181, 360, 16      # 学生里的真实分辨率(patch后)
x = torch.randn(B, Pl, Lat, Lon, C)
win = (2, 6, 12)                              # block 窗口
xp, _ = _pad3d(x, win); pPl, pLat, pLon = xp.shape[1:4]
w = block_partition(xp, win)                  # (nW*B, wz*wh*ww, C)
xr = block_reverse(w, win, B, pPl, pLat, pLon)[:, :Pl, :Lat, :Lon, :]
print("block 可逆:", torch.allclose(x, xr), " 窗口token:", w.shape)   # 必须 True
grid = (2, 6, 12)                             # grid 每组 token 数
xp2, _ = _pad3d(x, grid); gPl, gLat, gLon = xp2.shape[1:4]
wg = grid_partition(xp2, grid)
xg = grid_reverse(wg, grid, B, gPl, gLat, gLon)[:, :Pl, :Lat, :Lon, :]
print("grid 可逆:", torch.allclose(x, xg))                            # 必须 True
```
> 记忆点:`block` 连续切窗(view 成 `B,Pl//wz,wz,...` 再 permute 把窗口维聚到后面);`grid` 跨步散布(view 成 `B,gz,Pl//gz,...`,permute 顺序不同)。reverse 是逆 permute。pad 到整数倍、最后 crop 回 `[:Pl,:Lat,:Lon]`。

### 考点 3:QK-Norm 注意力
```python
import torch
from maxvit3d_student import Attention3D, set_sdpa
attn = Attention3D(dim=96, win=(2,6,12), num_heads=6)
x = torch.randn(1, 2*6*12, 96)               # (Bn, N, C),N=窗口token数
set_sdpa(False); y1 = attn(x)                 # 手写 softmax 路径
set_sdpa(True);  y2 = attn(x)                 # SDPA 融合路径(省显存)
print(y1.shape, " 无NaN:", not torch.isnan(y1).any().item(), " 两路一致:", torch.allclose(y1,y2,atol=1e-3))
```
> 记忆点:QKV `reshape(Bn,N,3,H,hd).permute(2,0,3,1,4)`;`q=F.normalize(q,-1); k=F.normalize(k,-1)`(余弦);温度 `clamp(logit_scale,max=log100).exp()`;SDPA 时把温度折进 q、bias 当 additive mask、`scale=1.0`。

### 考点 4:蒸馏双监督加权 L1
```python
import torch, torch.nn.functional as F
def wl1(x, y, w, lw): return lw * (F.l1_loss(x, y, reduction="none") * w).mean()
sw = torch.tensor([1.5,0.77,0.66,3.0]).view(1,4,1,1)   # 面通道权(来自config weights[:4])
pw = torch.ones(1,65,1,1)                                # 高空权(config weights[4:])
ss = torch.randn(1,4,721,1440); su = torch.randn(1,65,721,1440)   # 学生
ts = torch.randn(1,4,721,1440); tu = torch.randn(1,65,721,1440)   # 教师
tsf= torch.randn(1,4,721,1440); tua= torch.randn(1,65,721,1440)   # 真值
alpha = 0.5
ld = wl1(ss,ts,sw,0.25) + wl1(su,tu,pw,1.0)   # 对教师
lg = wl1(ss,tsf,sw,0.25)+ wl1(su,tua,pw,1.0)   # 对真值
loss = alpha*ld + (1-alpha)*lg
print("loss", float(loss), " 无NaN:", not torch.isnan(loss).any().item())
```
> 记忆点:面层权 0.25、高空层权 1.0、逐通道 weights;α=0.5 教师/真值各半;loss 在 float 下算(autocast 外)。

### 考点 5:Muon 优化器 —— Newton-Schulz 正交化
```python
import torch
def _ns5(G, steps=6, eps=1e-7):
    a,b,c = 3.4445,-4.7750,2.0315           # ★这三个系数要背
    X = G.bfloat16(); X = X/(X.norm()+eps)
    tp = G.size(0) > G.size(1)
    if tp: X = X.T
    for _ in range(steps):
        A = X@X.T; B = b*A + c*(A@A); X = a*X + B@X
    return (X.T if tp else X)
G = torch.randn(128, 64)
O = _ns5(G).float()
s = torch.linalg.svdvals(O)                  # 奇异值被压向 1(不是精确=1)
print("奇异值范围:", float(s.min()), float(s.max()))   # bf16+6步 约 [0.68,1.14] 即正常
```
> 注:Muon 的 NS **不追求精确正交**——那三个系数是 Keller Jordan 调好的,让奇异值快速落进 1 附近的一个带(约 [0.7,1.3]),用速度换"够正交"。所以奇异值不是全 1,别当 bug。
> 记忆点:动量 0.99 + Nesterov;`d = grad + mom*buf`(Nesterov)→ `_ns5(d)` → `p -= lr*scale*d`(scale=max(1,out/in)^0.5);**只作用 2D 骨干权重**,patchembed/recovery/embed/logit_scale 留给 AdamW。

### 考点 6:U 形 skip + 完整前向
```python
import torch
from maxvit3d_student import MaxVit3DStudent
import maxvit3d_student as M; M.set_sdpa(True)
m = MaxVit3DStudent(patch_size=(2,16,16), embed_dim=96, depths=(2,4,2),
                    num_heads=(6,12,6), mlp_ratio=2.0).eval()   # ← 4.35M 配方
x = torch.randn(1, 72, 721, 1440)
with torch.no_grad(): out_s, out_u = m(x)
print("out_s", out_s.shape, "out_u", out_u.shape,               # [1,4,721,1440] [1,5,13,721,1440]
      " 参数:", sum(p.numel() for p in m.parameters())/1e6, "M")
```
> 记忆点:`skip=x`(down 之前存)→ enc→downsample→mid(1/4 token 算力大头)→upsample→dec →`concat([x,skip],-1)`(通道翻倍)→ recovery(in_chans=2·embed)。改 `mlp_ratio` / `embed_dim` / `depths` 就换模型大小。

## 三、怎么判训练健康(看什么曲线)

- **比值 = 学生RMSE / 教师RMSE**:主指标,逐轮下降 → 健康;卡住不降 → 样本太少/欠拟合(60样本卡3.2x,113样本能到1.14x)。
- **train_loss** 单调下降;**val ACC** 升(0.96→0.98)。
- **Muon 组合 vs 纯 AdamW**:同数据 Muon 收敛快约 3 倍(ep10 就到 AdamW ep30 水平)。
- 达标线:比值 ≤ 1.3x。

## 四、★ 常见 bug 与修法(都踩过)

| 症状 | 原因 | 修法 |
|---|---|---|
| window reverse 后对不上 | partition/reverse 的 permute 维度顺序错 | 用考点1自测逐个验可逆;别改 permute 顺序 |
| loss / 输出 NaN | FFT/谱损失在 fp16 下不稳;或除零 | FFT 用 `.float()`(autocast 外);norm 加 eps;`clip_grad_norm_(…,1.0)` |
| OOM 被杀(无 traceback) | cgroup 内存**只有 59G**(不是 free 报的 503G);或激活太大 | int8 缓存(样本 435→216MB)、减 ktrain、bf16、`use_checkpoint=True` |
| 每轮 h5 读极慢(2小时/轮) | h5 读 4.85s/样本占大头 | **预处理教师输出到 int8 缓存**(只跑1次),之后每轮只算学生 |
| 换 Muon 后续训报错 | Muon 优化器状态与 AdamW 的 .ckpt 不兼容 | 换优化器要从头训;同优化器才能 resume |
| 容器跑一半没了 | 平台每天回收容器多次 | NFS 数据不丢,平台重启实例后 `bash run_train_fast.sh` 自动从 .ckpt 续;长跑用 `--bg` + 轮询 |
| 评测 RMSE 变天文数字 | 官方 result.py 取"前69通道",99通道测试集错位 | 用 `result_fixed.py`(按 metadata 名字选69) |
| hipBLASLt 越开越慢 / compile 崩 | DCU 上对 Pangu 不友好 | 别开 `TORCH_BLAS_PREFER_HIPBLASLT`、别用 `torch.compile`(见 playbook) |
| 计时不稳/偏低 | 异步设备没同步 | 前向前后 `torch.cuda.synchronize()` 再 `perf_counter` |
