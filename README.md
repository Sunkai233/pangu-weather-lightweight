## 关键技术点(详见 10 讲)

- **学生骨架**:MaxViT-3D U 形多尺度(block 局部 + grid 等距稀疏全局,线性复杂度对 DCU 稠密 GEMM 友好)+ 大 patch(token 52万→3.3万)
- **现代组件**:QK-Norm / RMSNorm / SwiGLU / LayerScale
- **蒸馏 + 真值监督**:DTP 双损失(α·教师 + (1−α)·真值),温度掺真值让近地面反超教师(1.19×→1.04×)
- **物理硬约束**:守恒校正层(架构级,resume 无损反涨,优于软约束)
- **减脂低秩**:训练时降维(权重满秩事后 SVD 否定,激活低秩才是训练时降维正解)+ Muon
- **推理优化**:fp16 权重 + 空间分块 tiling(923→548MB,bit-exact)+ 手写 HIP flash/GEMM 核
