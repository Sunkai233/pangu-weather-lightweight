1为什么蒸馏是主线

回到 L1 的设计哲学:用够小够快的学生拿 U/V,用蒸馏对齐教师守 W。这门课攻 W 的第一步,就是知识蒸馏——让 5.19M 的小学生"照着" 64.22M 的大教师学。

直觉:如果直接拿小学生去对着真值从零训,它容量太小、任务太难,很容易学不动或学歪。而教师已经把这个难任务学得很好了——让学生模仿教师的输出,等于站在教师肩膀上,用小规模就能逼近大模型的表达力。这就是"蒸馏":把大模型的知识"蒸"进小模型。

2蒸馏 vs 从头对真值训

baseline:小学生直接对真值从头训

监督信号只有真值(t+6h 真实场)。但真值是"硬标签"——只告诉学生"正确答案是这个数",没告诉它大气各处该怎么协同。小容量学生独自啃这个高维强耦合任务,收敛慢、易学歪。

升级:先蒸馏教师(软标签)

教师输出是平滑的"软标签",隐含了大量"大气各变量之间怎么配合"的结构信息(比 0/1 硬标签富得多)。学生模仿教师,相当于教师把"该怎么想"手把手教给它,收敛快、学得稳,先把 W 的大盘守住。

但蒸馏有个天花板

纯蒸馏的目标是"越像教师越好"。这意味着学生最好也就逼近教师——学生的精度永远 ≤ 教师(RMSE 永远 ≥ 教师)。要想超过教师,光模仿不够,必须再引入别的信号。这就引出了第 3 节的 DTP 双损失。

3DTP 双损失:破天花板的起点

DTP(双路深监督)的思想极简:一边学教师,一边学真值,两个损失加权求和。

loss = α · L蒸馏(学生, 教师输出) + (1−α) · L真值(学生, t+6h 真实场)
α = 0.5:一半照教师学(守表达力)、一半照真值学(拿真本事)
为什么掺真值能"超教师"

纯蒸馏时学生天花板 = 教师;而 (1−α)·真值 这一路不受教师限制,它直接盯着真实答案。对某些通道(尤其温度),学生在真值这一路上可以学到教师都没学好的东西,从而在这些通道反超教师。α=0.5 是"守表达力"和"拿真本事"之间实测的平衡点。L6 会专门展开怎么把这一路用足去攻近地面洼地。

# distill_train.py:94-95 / distill_scnet.py:147-149 DTP 双损失 ld = weighted_l1(student_out, teacher_out) # 蒸馏损失:对教师软标签 lg = weighted_l1(student_out, truth_t6h) # 真值损失:对真实未来场 loss = args.alpha * ld + (1 - args.alpha) * lg # α=0.5 加权

4官方加权 L1:让损失对标评分口径

两路损失都不是普通的 MSE/L1,而是逐通道加权的 L1——权重直接取自官方 config,对齐赛题 W 的评分口径。

# distill_cache.py:20-21,267 官方逐通道权重 WEIGHTS_surface = [1.50, 0.77, 0.66, 3.00] # mslp / u10 / v10 / t2m WEIGHTS_upper = [3.0]*13 + [0.6]*13 + [1.5]*13 + [0.77]*13 + [0.54]*13 # z/q/t/u/v ×13层 loss = (F.l1_loss(x, y, reduction='none') * w).mean() # 地表因子0.25、高空1.0
数学原理 · 为什么加真值那一路能突破天花板

DTP 是一个多目标加权的凸组合,梯度也是两路的加权和:

L = α·L蒸馏(f, T) + (1−α)·L真值(f, y)　,　∇L = α∇L蒸馏 + (1−α)∇L真值

纯蒸馏(α=1)的最优解 = 完美复制教师 T,所以学生误差 ≥ 教师误差,这就是天花板的数学来源。一旦 (1−α)>0,损失的最小值点不再是"等于教师",而是"教师与真值的加权折中"——在真值比教师准的通道(如近地面温度),折中点会偏离教师、更靠真值,于是反超教师。α 就是控制这个折中位置的旋钮。

参考项目 · FitNets(Romero 2015)+ RKD(Park et al., 2019)
抽象问题蒸馏不止能对齐"输出",还能对齐中间特征(FitNets 的 hint)或样本间关系(RKD 的距离/角度)——本质都是"让小模型继承大模型的某种结构"。
怎么变好FitNets 用中间层监督训出更深更薄的学生;RKD 对齐 batch 内样本关系,补回流形结构、提升泛化,且几乎不加参数。
桥接到我们我们的输出蒸馏是最基础的一种;在同一"结构对齐"框架下,特征蒸馏、关系蒸馏可以叠加到气象场上补回被 patch16 丢掉的流形信息(RKD 10 行代码、0 参数,直接加在加权 L1 上就能再挤一点)。理解"蒸馏=结构对齐"这个抽象,就知道还有多少可叠加的信号没用。

5教师冻结与软标签

教师全程冻结

教师是官方 Pangu(载 model_bak.pth),参数完全不更新,只当"老师"用——前向一次生成软标签,反传的梯度只流进学生。教师就是一把固定的尺子。

软标签为什么值钱

教师对每个格点输出的是连续、平滑、物理自洽的预测场,携带了"大气各处该怎么协同"的丰富信息。学生对着它学,比只对着真值硬标签学要好带得多。

副作用:教师前向很贵 → 催生了缓存

每个训练 step 都跑一遍 1.8G 的教师前向,慢得离谱(~800-1900ms/step)。破法:一次性把教师软标签全算好、缓存起来(RAM 或落盘),之后训练循环不再碰教师,单 step 直接快到 ~900ms 甚至更少。这套数据/缓存工程是 L 训练效率的关键,详见后续数据管线。

6训练框架:一套现代配方

学生用的是一套成熟的现代训练配方(distill_scnet.py)。这套配方里每个部件都不是随手加的,下面逐个把它解决什么问题、机制是什么、为什么这么设、代价在哪讲透。

① AdamW + 激进动量 β₂=0.95优化器

是什么:AdamW = Adam + 解耦权重衰减。Adam 给每个参数维护两个动量——一阶动量 m(梯度的滑动平均)和二阶动量 v(梯度平方的滑动平均),更新公式 θ ← θ − lr·m̂ / (√v̂ + ε)。除以 √v̂ 相当于给每个参数一个自适应学习率:梯度一直很大的参数被"踩刹车",梯度小的被"给油"。

为什么 β₂=0.95 比默认 0.999"激进":β₂ 控制 v 的记忆长度,有效平均窗口 ≈ 1/(1−β₂)——0.999 是回看 1000 步,0.95 只回看 20 步。中小模型训练总步数少、梯度噪声大,0.999 太"迟钝"(要上千步才把 v 估准,前期自适应学习率是错的);0.95 让 v 紧跟当前梯度尺度、反应快,更适合小模型短训练。

weight_decay=0.05(AdamW 的"W"):解耦的权重衰减,每步直接 θ ← θ·(1 − lr·wd),不经过梯度和动量(这正是 AdamW 相对 Adam 的修正)。作用是 L2 正则、压权重范数防过拟合。偶尔升到 0.15–0.2:更狠地压权重,连带把激活幅度也压下来 → 缓解 bf16/fp16 下"激活太大变 inf"的数值溢出。

② warmup + 余弦退火(学习率日程)LR 调度

warmup(前 ~5 epoch 线性升温):lr 从 0 线性升到 base_lr。为什么:开局权重是随机的、梯度方向乱,直接上大 lr 会震荡甚至发散;更关键的是 Adam 的二阶动量 v 一开始样本太少估不准,此时大 lr 会被错误的自适应缩放放大。warmup 给 v 一个"预热期"先估准,再升到满 lr。

余弦退火(之后平滑降到近 0):lr(t) = ½·base·(1 + cos(π·(t−t_w)/(T−t_w)))。为什么用余弦而不是阶梯式降:余弦在末端导数趋于 0 → lr 变化越来越慢 → 模型平滑地落进极小点盆地;阶梯式突然降 lr 会让 loss 抖一下。后期的小 lr 负责精细收敛。

③ 梯度裁剪 1.0稳定性

是什么:每步反传后,若全局梯度范数 ‖g‖ > 1.0,就整体缩放 g ← g·(1.0/‖g‖)——只缩模长、不改方向,把这一步的"步长"封顶。

为什么必须有:①bf16 混精偶尔冒出梯度突刺(某一步梯度爆大,一步就能把权重推飞、后面全崩);②气象场不同变量的梯度量级差好几个数量级(风 vs 温度),合起来范数很不稳。裁剪相当于训练的"保险丝",给每步步长封个上限,防一个坏 step 毁掉整轮训练。1.0 是常用且稳妥的阈值。

④ EMA 权重(衰减 0.999)泛化

是什么:训练时另存一份"影子权重" θ_ema,每步 θ_ema ← 0.999·θ_ema + 0.001·θ。它是权重的指数移动平均,近似对最近 ~1000 步的权重做加权平均(窗口 ≈ 1/(1−0.999))。

为什么更好:Adam/SGD 到了极小点附近并不会停住,而是在盆地里持续震荡,单步权重 θ 只是"某个震荡瞬间的位置"。EMA 把这些震荡平均掉 → 落点更靠近盆地中心、更平坦 → 泛化更好。学生训练波动大,EMA 尤其有效:eval 和保存都用 θ_ema,实测常比末步权重高 1–3%,几乎是白赚的分。

⑤ bf16 自动混精显存/速度

是什么:autocast 让 forward 的矩阵乘/卷积走 bf16(16 位 = 1 符号 + 8 指数 + 7 尾数),而梯度累加、优化器状态(m/v)保 fp32。"自动"指框架按算子的数值安全性决定谁降精度。

为什么是 bf16 而不是 fp16:bf16 的指数位和 fp32 一样多(8 位)→动态范围一样大,不易上溢/下溢,训练不用额外的 loss scaling;代价是尾数只 7 位(精度低),但前向对精度不敏感,关键的梯度累加在 fp32 里做,所以整体无精度损失。fp16 只有 5 位指数、范围小,训练易溢出、要额外 scaling 伺候。

收益:forward 显存 ↓40–50%、更快(DCU 上 bf16 吃半精度算力约 2×),精度不掉——纯赚。

⑥ 梯度检查点(gradient checkpointing)显存↔时间

是什么:反传算梯度需要用到前向时的中间激活。默认会把每一层的激活都存下来(很占显存)。检查点只存少数"关卡"层,反传到某一段时从最近的关卡重新前向算一遍激活——用重算(计算)换存储(显存)。

权衡:显存 ↓~50%(不再常驻全部中间激活),代价是多一次前向、时间 ↑~30%。所以它是个可调开关:数据规模大、模型深、显存吃紧时打开(比如上全量数据训);显存够用时关掉换速度。

7双指标早停:判优必须看真值

训练时用两个验证指标盯着,分别对应"技能"和"表达力":

val_gtL1(对真值,优先)

学生预测对 t+6h 真值的纬度加权 L1。它衡量的是真实预报技能——最接近赛题 W 的口径,判优主要看它。

val_match(对教师)

学生预测对教师输出的相对逼近度。它衡量的是模仿得像不像——反映表达力,但像教师 ≠ 预报准。

一条血泪教训(记忆里反复强调)

判优必须看 val_gtL1(对真值 RMSE),不能只看 val_match(对教师)。因为掺了真值后,学生在某些通道会偏离教师但更接近真实——这时 val_match 会"变差",但其实是好事。只盯 val_match 会把真正涨技能的模型误杀。每轮存两份:最优单存 + 断点 .ckpt(供 resume)。

8HIP/DCU 视角 + 本课要点

训练在哪跑、DCU 上要注意什么

蒸馏训练主要在 GPU 训练机上跑(mitai 4×4090 / DeepLN V100 / abc66 / funhpc),再把最优权重拿到海光 DCU 上部署评测。DCU 上训练要注意:bf16 混精吃半精度算力、梯度检查点省显存、缓存避免重复跑教师前向(教师在 DCU 上是 model_bak.pth 1.8G)。判优的最终标准始终是在 DCU 上对真值的 RMSE,不是训练机上的 val_match。

本课要点(记住这 6 条)
  1. 蒸馏是主线:让 5.19M 小学生照着 64.22M 教师(冻结)学软标签,站在教师肩膀上守住 W 大盘。
  2. 纯蒸馏有天花板:目标是"像教师"→学生精度永远 ≤ 教师。要超教师必须引入真值。
  3. DTP 双损失:α·L蒸馏(对教师) + (1−α)·L真值(对 t+6h 真实),α=0.5。真值这一路不受教师限制,是破天花板的起点(L6 展开)。
  4. 官方加权 L1:逐通道权重(2m 温/位势 z ×3.0 最高)直接对标赛题 W 评分口径,不做无用功。
  5. 训练配方:AdamW(betas 0.9/0.95)+ warmup 余弦 + 梯度裁剪 + EMA(0.999)+ bf16 + 梯度检查点。EMA 权重常更优。
  6. 判优看真值:val_gtL1(对真值,优先)+ val_match(对教师)双指标;只看 val_match 会误杀真正涨技能的模型。
