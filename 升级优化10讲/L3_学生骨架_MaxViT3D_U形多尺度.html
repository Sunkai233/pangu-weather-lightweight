1骨架设计的三个硬约束

学生不是随便设计的,它同时被三条硬约束框住——这三条直接来自 L2 对教师和气象场的理解:

约束① I/O 必须对齐教师

入 [B,72,721,1440]、出 surface[B,4]+upper[B,5,13],逐通道一致。所以 stem/head 直接复用官方 PanguEmbedding/Recovery,学生只改中间骨干。

约束② 必须保 3D 结构

大气是三维耦合的,不能拆成独立 2D。学生仍把 13 层当深度维,做 3D 分块注意力(局部窗口和全局都是 3D 的)。

约束③ 要全局但要便宜

天气系统跨千公里,必须有全局感受野;但教师的 O(N²) 窗口注意力太贵。学生要找次线性又对 DCU 稠密 GEMM 友好的全局机制。

第③条是骨架设计的最大挑战,也是 MaxViT 被选中的原因。

2MaxViT 是什么:block + grid 交替

MaxViT 的核心思想极简却强大:把注意力拆成两种,交替堆叠——

block 注意力(局部)

把空间切成连续的小窗口,窗口内做全注意力。抓局部细节(锋面、局地环流)。像放大镜。

grid 注意力(全局)

按固定步长等距抽样,把散布全域的 token 凑成一组做注意力。抓全局形势(急流、大尺度波)。像广角镜。

两者复杂度都是线性级(不是 O(N²)),交替堆叠后每个 token 既看到近处细节、又能通过 grid 一跳摸到全球。学生把这套 2D 的 MaxViT 思想搬进 3D 气象场(分块都带气压层维)。

3block 注意力:局部抓细节

block 分块(block_partition)就是标准的窗口注意力:把 (B, 层, 纬, 经, C) 的场切成 连续 的 (2,6,12) 小窗口,每个窗口内部的 2×6×12=144 个 token 互相做注意力。

# 连续窗口 = 局部;相邻 token 落在同一个注意力组 x = x.view(B, Pl//wz, wz, Lat//wh, wh, Lon//ww, ww, C) x = x.permute(0,1,3,5, 2,4,6, 7) # 把窗口内的 (wz,wh,ww) 聚到一起 return x.view(-1, wz*wh*ww, C) # (组数, 144, C) → 组内做注意力

window (2,6,12) 表示每个窗口覆盖 2 个气压层 × 6 格纬 × 12 格经——一小片连续的局部区域。这负责把局地的锋面、地形环流等细节刻画清楚,是精度 W 的"细节保真"部分。

4grid 注意力:骨架的灵魂

grid 是这套骨架最关键的设计,直接决定了"怎么用便宜的代价拿到全局感受野"。它和 block 只差一个 permute,思想却完全不同。

# 跨步等距 = 全局;一个注意力组里的 token 均匀散布在整个地球 x = x.view(B, gz, Pl//gz, gh, Lat//gh, gw, Lon//gw, C) x = x.permute(0,2,4,6, 1,3,5, 7) # 把"等距抽样点"聚成一组(注意与 block 的 permute 不同) return x.view(-1, gz*gh*gw, C) # 每组 token 相隔 (Pl/gz, Lat/gh, Lon/gw) 均匀分布
grid 为什么对国产 DCU 特别友好
  • 规整稠密:grid 分组后每组 token 数固定、形状规整,注意力就是标准的批量稠密矩阵乘(GEMM),能直接吃满 DCU 的 Matrix Core——不像教师的移位窗口会产生不规则 gather/mask。
  • 复杂度低:全局感受野但代价约 O(N·M)(M=组内 token 数,远小于 N),而非 O(N²)。
  • 无内容依赖:分组是固定步长,不需要动态索引,cudagraph/编译都友好。

一句话:grid 用"等距抽样"把全局注意力整理成了国产卡最擅长的规整矩阵乘。这是学生能又快又准的骨架级原因。

(旁注:源码里 grid 之外还预留了 spectral 频域全局和 fpa 原型自适应全局两种更高级的全局支路,它们是 O(N·M) 线性注意力的进阶路线,留到 L7 物理先验 展开。本课骨架用默认且最稳的 grid。)

数学原理 · grid 稀疏与 U 形下采样的算力账

grid 全局:把 N 个 token 分成"每组 M 个等距点、共 N/M 组",注意力只在组内算 O(M²),总量:

全局 O(N²)　⟶　grid O(N·M)　(M 固定,故线性于 N)

U 形下采样:FFN/注意力成本都随 token 数走(FFN 是 O(N·d²))。把主干放到下采样后的 N/4 个 token 上,主干算力直接降到约 1/4——这就是"把最深的计算放低分辨率"省 V/U 的数学根据。

参考项目 · MaxViT(Tu et al., 2022)+ U-Net(Ronneberger et al., 2015)
抽象问题如何用线性复杂度拿到全局感受野?MaxViT 把注意力分解成 block(局部窗口)+ grid(等距稀疏全局)交替,两者都线性,组合起来 O(N) 覆盖全局。U-Net 则用"编码→下采样→解码 + skip"把主干放低分辨率。
怎么变好MaxViT 成为高效视觉骨干(分类/检测 SOTA 级且线性);U-Net 是分割/密集预测的通用范式,几乎所有像素级任务都在用。
桥接到我们气象场就是规则网格上的密集预测,和 MaxViT/U-Net 的图像任务底层同构(2D/3D 网格上的密集映射)。MaxViT 的"局部+稀疏全局线性分解"正好解我们"要全局感受野又要省"的矛盾;U-Net 的"主干放低分辨率"直接给 V/U。所以把这两个视觉范式 3D 化搬到气象,天然契合。

5U 形多尺度:把主干算力放到 1/4 token

和教师一样,学生用 U 形 结构,但把"下采样省算力"这一招用到极致:

6大 patch:token 数暴降(最大的杠杆)

省 token 还有一个更狠的杠杆:patch 切得更大。教师用 patch=(2,4,4),学生用 patch=(2,16,16)——纬经方向一个 patch 覆盖 16×16 而非 4×4 个格点。token 数直接掉一个量级:

大 patch 的取舍

patch 越大越省,但太大会丢细节、掉 W。patch=16 是实测的甜点:配合 grid 全局(1.14× 那档,见记忆 p16grid)在 V/U 和 W 之间取到好平衡。"切多大 patch"本身就是一个可调超参,后面 L8 的减脂/架构搜索会系统地扫这类维度。

7残差预测:让网络只学 6 小时的"增量"

骨架里还藏了一个提精度的小开关 residual:输出不是直接预测 t+6h 的场,而是 预测"增量"再加回输入:

# out = 输入场 + 网络学到的 6h 变化量 out_surface = out_surface + x_in_s out_upper = out_upper + x_in_u

为什么有用:6 小时里大气变化很小,t 和 t+6h 的场高度相似(数据残差比只有 0.07–0.12)。让网络去学"从 t 到 t+6h 变了多少"这个小增量,比让它从零重建整个未来场轻松得多——相当于给网络一个极好的初值,大幅减负、整体提精度。这在物理预报里是常见且有效的技巧。

8骨架配置总览 + HIP 视角 + 要点

embed_dim96教师 192 的一半,更窄
depths(enc,mid,dec)2, 4, 2每档若干对 block+grid,mid 最深

grid 全局→ 规整稠密 GEMM,吃满 Matrix Core(对标 Tensor Core);大 patch + U 形下采样→ 主干 token 少,访存/算力都轻;RMSNorm/SwiGLU(L4 细讲)→ 都是 element-wise + GEMM,没有奇怪算子。 相比教师的移位窗口(不规则 gather、大 attn_mask buffer),学生骨架是为规整稠密计算而生的——这让它在 DCU 上用 rocBLAS/hipBLASLt 就能跑得又快又稳。L10 还会手写 HIP flash 核把注意力再压一刀。

本课要点(记住这 6 条)
  1. 三约束:I/O 复用官方 stem/head(对齐教师)、保 3D 结构、要便宜的全局感受野。第三条催生了 MaxViT 选型。
  2. MaxViT = block + grid 交替:block 连续窗口抓局部细节,grid 等距抽样抓全局形势,都是线性级复杂度。
  3. grid 是灵魂:等距散布的 token 凑一组做注意力,一跳看全球;分组规整→标准稠密 GEMM,对 DCU 的 Matrix Core 极友好。
  4. U 形多尺度:主干最深的计算全放在下采样后的 ~1/4 token 上,两端浅层抓细节 + skip 补回。直接省 V/U。
  5. 大 patch(2,16,16)是最粗的省 token 杠杆:521280 → 33120(≈1/16),细节靠 stem/block/skip 补。
  6. 残差预测:只学 6h 小增量(残差比 0.07–0.12),给网络好初值、减负提精度。骨架配置 embed96/depths2-4-2/grid → 5.19M。
