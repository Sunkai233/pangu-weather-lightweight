L6破天花板:真值监督与近地面提分

这是全项目提分最关键的一节。L5 的 DTP 掺进了真值,这一课把真值这一路用到极致—— 让近地面温度真的反超教师,再用一整套精准补洼地的招式,把 W 从 35.63 一路冲到 38.44。过程里还踩了一个"共享头漂移"的大坑,修法很有意思。

1洼地在哪:近地面 4 项

L1 埋过伏笔:W 的短板集中在近地面。蒸馏后,高空场(500/700 hPa 的 z/t/q/u/v)对齐得很好(1.07–1.13×),但越靠近地面越差——地形、边界层、昼夜变化都在近地面最剧烈。

2招式一:温度掺真值——让近地面真超教师

L5 说过:蒸馏那一路的天花板 = 教师。要让近地面超教师,就得让它多吃真值。做法是只对温度通道掺真值,其它通道仍纯蒸馏(保住教师给的流形结构):

# distill_truth.py:35-36,484-493 只温度通道掺真值 T_SURF_IDX = [3] # 2m_temperature(地表第4通道) T_UPPER_NEAR = [26,27,28] # 近地面温度层 t@1000/925/850 # 温度通道:α·教师 + (1-α)·真值;其它通道:纯蒸馏(对教师) loss = distill_all + truth_alpha * l1(stu[temp_mask], truth[temp_mask])

3大坑:共享 recovery 头致高空温度漂移

但如果只监督近地面这 3 层温度,会踩一个隐蔽的大坑——净 W 反而降了。原因藏在学生的结构里。

4修正:full-temp 全 13 层监督

修法很直接:别只监督近地面 3 层,把全 13 个温度层都加上真值锚(--full-temp)。每层都有真值盯着,共享头就没法为了近地面而牺牲高空。

只监督近地面 3 层

t@1000/925/850 ✓ 变准
t@500/200/100 ✗ 被共享头带歪(200 层漂到 1.44×)
→ 净 W 反降

full-temp 全 13 层监督

每个温度层都有真值锚
共享头不能顾此失彼
→ 近地面涨、高空不塌,净 W 真涨

# distill_truth.py:144-145,175-180 --full-temp:温度真值覆盖全 13 层 if args.full_temp: T_UPPER_IDX = list(range(26, 39)) # t 的全部 13 层(不只近地面 3 层)
一条通用规律

凡是多个输出共享一个头/一段参数的结构,只监督其中一部分,会污染其余部分。要么全监督(full-temp),要么把头拆开。这个坑在多任务/多输出模型里非常常见——记住"共享头 = 牵一发动全身"。

5精准补洼地:四招加权

温度搞定后,还有风/湿/气压的洼地。用四招逐通道/逐区域的加权精准补,每招都对着 W 归因发现的短板下手:

protect:锚定风/湿/位势,防被温度带歪保护

温度掺真值时,共享 backbone 也可能把 u/v/z/msl 带歪。给这些通道的蒸馏权重 ×1.5–2.0,把它们牢牢锚在教师上,不让温度训练把它们拽跑。protect=1.5 时 u/v/z 恢复 ~0.5–1%。

# distill_truth.py:146-148,227-233 w[protect_channels] *= protect # u/v/z/msl 蒸馏权重加倍,锚定教师
chan-reweight:补低层风/湿补洼地

W 归因发现劣化最集中的是低层 u/v + 10m 风 + q 比湿——它们被 patch16 的粗粒化伤得最重。对这几个通道单独 ×倍数,逼学生重点练。低层 RMSE ↓ 10–20%。

region-weight:补陆地/高地形/极地补洼地

误差不只按通道分,也按地理分:陆地(地表过程复杂)、高地形、极地(|lat|>60)蒸馏最不足。给这些格点 ×倍数加权。陆地/极地 RMSE ↓ 5–8%。

ivw:逆方差权重,放大温度小增量的梯度梯度均衡

残差预测下,网络学的是 6h 增量。温度增量很小(~0.07–0.12K),风的增量大(m/s 级)——温度的梯度会被风压制。用每通道 1/std(增量) 加权,自动把温度小增量的梯度放大,让它学得动。

# distill_cache.py:175-184 --ivw 增量逆方差权重 ch_std = incr[:,c].std() # 每通道 6h 增量的标准差 w[c] *= 1.0 / (ch_std + eps) # 小增量通道(温度)权重放大

6训练实操:真值监督阶段怎么跑

更小的学习率 + resume 续训

真值监督是在蒸馏好的权重上接着精调,不是从头训。lr 6e-5(比主训 6e-4 小一个量级,防把已学好的搞崩)+ --resume 从最优 .ckpt 继续。

连续 6h 真值对

真值监督需要"当前场 → 6h 后真实场"的成对数据(era5_cont,相邻恰好差 6h,约 482 对)。build_pairs 校验时间戳差 6h 才配对。

实操细节:关掉 DTP 动态加权、用 .ckpt

真值精调阶段有几个踩过的坑:①这一阶段常关掉 DTP 动态加权(避免和手动的 protect/reweight 打架)②resume 要用带优化器状态的 .ckpt 而非纯权重 .pth,否则动量/EMA 丢失会抖 ③判优只认对真值的 RMSE(见 L5)。

数学原理 · 共享头污染的梯度耦合

所有温度层共用一组 recovery 头参数 θ,第 ℓ 层输出 tℓ = head(θ; featℓ)。只监督近地面 3 层时,梯度只由这 3 层驱动:

∂L/∂θ = Σℓ∈{近地面3层} (∂L/∂tℓ)(∂tℓ/∂θ)

θ 朝"让近地面最优"的方向移动。但没被监督的 t@200 也依赖同一个 θ(∂t200/∂θ ≠ 0),θ 一变,t@200 跟着漂——这就是"共享头污染"的数学本质:参数共享导致输出间的雅可比耦合。修法(full-temp)= 把全 13 层都放进 L,让 ∂L/∂θ 被所有层平衡,θ 无法为近地面牺牲高空。

参考项目 · GraphCast(Lam et al., Science 2023)+ Stormer / Aurora
抽象问题单步预报优化的是"1 步准",但气象要长期准。多步 rollout:让模型自回归滚动 N 步,对第 N 步真值算损失,直接把训练目标对齐评测目标(长期预报技能)。
怎么变好GraphCast 靠 rollout 微调,在 10 天全球预报上超越顶级数值模式 ECMWF-HRES,是 AI 气象的里程碑;Stormer/Aurora 同样以 rollout 训练拿到长期技能。
桥接到我们我们的真值监督是"1 步对真值",正是 rollout 的 N=1 特例。底层数学问题完全一样——最小化对真实未来场的预报误差,只是展开几步。所以"多步 rollout 微调"是我们继续攻 W 的自然延伸(把 N=1 推广到 N>1),同一套真值优化框架直接适用。

7结果:W 35.63 → 38.44,平衡的艺术

这一整套真值监督招式叠起来(再配 L7 的物理约束和更好的权重),把 W 从基准的 35.63 冲到了最终的 38.44——正是总分从 94 顶到 96.12 的主要来源。

核心心法:破天花板是"平衡的艺术"

真值监督的每一招都是双刃:掺真值涨近地面、但会带歪高空(→full-temp 修);拉温度、但会拽跑风位(→protect 锚)。提分的本质不是猛加真值,而是"哪里补、哪里守"的精细平衡。这也是为什么判优必须逐通道看、必须看对真值的 RMSE——一个总分背后是一堆此消彼长的通道账。

8HIP/DCU 视角 + 本课要点

真值监督与 DCU 判卷

真值监督在 GPU 训练机上精调,但最终成败由 DCU 判卷说了算。要特别小心:训练机上对真值 RMSE 涨了,不代表判卷涨(口径、数据、混精都可能有差)。所以每个真值监督变体产出后,都要拿到 DCU 上按官方口径跑一遍再定优劣。这与 Qwen 项目"判卷才是精度唯一真理"的教训一致——离线指标只作参考,别当结论。

本课要点(记住这 6 条)
  1. 洼地在近地面:蒸馏后高空好(1.07×)、近地面差(1.19×)。这一课全部招式都冲着近地面 4 项。
  2. 温度掺真值破天花板:只对温度通道掺真值,近地面温度从 1.19×(打不过教师)压到 1.04×(反超),温度权重最高含金量大。
  3. 大坑:共享 recovery 头:只监督近地面 3 层温度→共享头把没监督的高空温度带歪(t@200 漂到 1.44×)→净 W 反降。
  4. 修正:full-temp 全 13 层:每个温度层都加真值锚,共享头顾不了此失彼。规律:共享头=牵一发动全身,要么全监督要么拆头。
  5. 四招补洼地:protect(锚风/位势防带歪)、chan-reweight(补低层风/湿)、region-weight(补陆地/极地)、ivw(放大温度小增量梯度)。
  6. 破天花板=平衡的艺术:每招都双刃,精细"补与守"才涨净分。W 35.63→38.44 是这套招式(+L7 物理)的成果;判优认 DCU 判卷。
