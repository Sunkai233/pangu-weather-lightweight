1为什么要逐个换零件

骨架(L3)决定了信息怎么在多尺度间流动;但每个 block 内部的零件决定了训练稳不稳、参数省不省、能不能更深更窄。 小模型要在 5.19M 下逼近 64.22M 教师,靠的就是"把每个零件都换成 2024–2026 年最省最稳的现代选择"。

2QK-Norm:余弦注意力 + 每头可学习温度

注意力的核心是 softmax(q·kᵀ · scale) · v。问题出在 scale 和 q·k 的幅度上。

baseline:标准点积注意力

用固定缩放 q·kᵀ / √d。训练中 q、k 的范数会漂移变大,点积幅度跟着涨→softmax 进入饱和区(某几个 token 独占权重)→梯度消失、深层训练不稳、对初始化敏感。

升级:QK-Norm(SwinV2 风格)

① 先把 q、k L2 归一化→点积变成余弦相似度,幅度天然被限制在 [−1,1];② 缩放改成每个头可学习的温度 τ(初始 log10、上限 clamp 到 log100)。稳、可更深更窄、对初始化不敏感。

# maxvit3d_student.py:181-191 Attention3D q = F.normalize(q, dim=-1) # QK-Norm:q 单位化 k = F.normalize(k, dim=-1) # k 单位化 → q·kᵀ 即余弦 scale = torch.clamp(self.logit_scale, max=math.log(100.0)).exp() # 每头可学习温度 τ attn = (q @ k.transpose(-2,-1)) * scale # 余弦 × τ,幅度可控 attn = attn + self.bias() # 加相对位置偏置(第 3 节) attn = attn.softmax(dim=-1)

3RelPosBias3D:3D 相对位置偏置

注意力本身不知道 token 之间的空间位置(它只看内容相似度)。得显式告诉它"谁离谁近"。学生沿用 Swin 的做法,但做成 3D 的:

对窗口/网格内每一对 token,按它们的 3D 坐标差(层差,纬差,经差)去查一张可学习的偏置表,把偏置加到注意力分数上。

用相对位置而非绝对位置:平移一段的两个 token,相对关系不变→偏置一致→参数复用、更省、泛化更好。表大小 (2a−1)(2b−1)(2c−1)×heads,很小。

# maxvit3d_student.py:126-152 RelPosBias3D(Swin 风格 3D 版) rel = coords[:,:,None] - coords[:,None,:] # 每对 token 的 (层差,纬差,经差) idx = rel.sum(-1) # 3D 坐标差 → 一维查表索引 bias = self.table[idx] # 查可学习偏置表 → (N,N,heads) # 前向:attn = 余弦×τ + bias 再 softmax

(注:教师 Pangu 用的是更重的 Earth-specific 绝对位置偏置——见 L2。学生用轻量的相对偏置 + QK-Norm 可学习温度来近似,省参又够用。)

4RMSNorm:换掉 LayerNorm

归一化在每个 block 里用了两次(注意力前、FFN 前),是高频操作,选轻的很划算。

baseline:LayerNorm

y = (x − μ)/σ · γ + β。要算均值 μ、方差 σ,再中心化、缩放、平移(两组参数 γ、β)。步骤多、访存多。

升级:RMSNorm

y = x / RMS(x) · γ,其中 RMS(x)=√(mean(x²))。去掉中心化(不减均值)和平移(无 β),只按均方根缩放。计算更轻、显存更省、精度等价——现代 LLM 标配。

# maxvit3d_student.py:54-62 RMSNorm n = x * torch.rsqrt(x.pow(2).mean(-1, keepdim=True) + eps) # 只除均方根,无减均值 return n * self.weight # 只有 γ,没有 β
为什么"少算"反而不掉精度

大量实践(LLaMA/Qwen 等)证明:Transformer 里减均值那一步贡献很小,方差缩放才是关键。去掉中心化和 β,既省了算力/显存,又几乎不影响效果。对 DCU 这种访存敏感的卡,少一遍 reduce 尤其值。

5SwiGLU:换掉普通 MLP

FFN(前馈网)是每个 block 里参数量最大的部分。升级它既要更强、又不能涨参。

baseline:标准 FFN

W2 · GELU(W1·x),隐藏维通常 4×d。一条直筒:升维→激活→降维。

升级:SwiGLU 门控

W2 · ( SiLU(W1·x) ⊗ W3·x )。多一条门控支路 W3,用 SiLU(x·W1) 逐元素乘 (x·W3) 动态控制信息通过多少。表达力更强。

# maxvit3d_student.py:65-77 SwiGLU hidden = int(mlp_ratio * dim * 2 / 3) # ★隐藏维取 8/3·d(不是 4d) a, b = self.w12(x).chunk(2, dim=-1) # 一次算出两支:a 走激活,b 当门 return self.w3(F.silu(a) * b) # SiLU(a)⊗b 再降维
关键巧思:门控多一条支路,却不涨参数

门控本来会多一个矩阵 W3(参数变多)。做法是把隐藏维从 4d 降到 8/3d(≈2.67d)——三个矩阵各变窄,总参数正好和标准 4×GELU 的 FFN 相当。于是"白拿"了门控的表达力提升。学生更进一步用 mlp_ratio=2.0 继续缩,进一步省参(L3 骨架配置)。

6LayerScale + DropPath:稳训练的两个小零件

LayerScale:让残差分支"慢慢长大"

每个残差分支的输出乘一个逐通道可学习标量 λ,初始极小 1e-5。开局时残差分支几乎为 0(网络≈恒等,极稳),训练中 λ 自己慢慢长大、逐步贡献。深层网络不会一上来就被噪声冲垮。

DropPath:随机深度正则

训练时按概率整条丢掉某个残差分支(该样本这一层直接走 shortcut)。等价于随机训练不同深度的子网络,是强正则,防过拟合、增鲁棒。推理时关闭。学生按层线性递增丢弃率(浅层少丢、深层多丢)。

# maxvit3d_student.py:307-331 AttnFFN.forward —— 两个零件都在残差里 x = shortcut + self.drop_path(self.ls1 * h) # 注意力子层:LayerScale ls1 + DropPath x = x + self.drop_path(self.ls2 * self.mlp(self.norm2(x))) # FFN 子层:LayerScale ls2 + DropPath
数学原理 · 三个零件各自的一行公式

QK-Norm:单位化后点积就是余弦,天然有界,再乘可学习温度 τ 调锐度:

q̂·k̂ = (q/‖q‖)·(k/‖k‖) = cos θ ∈ [−1, 1]　→　attn = τ·cos θ

RMSNorm:去掉减均值和偏置,只按均方根缩放(比 LayerNorm 少两步):

y = x / √( mean(x²) + ε ) · γ　(无 μ、无 β)

SwiGLU:门控 FFN,隐藏维取 8/3·d 使参数与标准 4d FFN 相当:

FFN(x) = ( SiLU(xW₁) ⊗ xW₃ ) W₂　,　hidden = 8/3·d
参考项目 · 这套组件都来自大模型(LLM/ViT)的现代实践
出处QK-Norm/余弦注意力=SwinV2(Liu 2022);RMSNorm=Zhang & Sennrich 2019(LLaMA/Qwen 标配);SwiGLU=Shazeer 2020《GLU Variants Improve Transformer》;LayerScale=CaiT(Touvron 2021)。
怎么变好它们分别解决"注意力 logits 爆炸训不稳""归一化太重""FFN 表达力/参数效率""深层 ViT 崩",让大模型能训得更深、更稳、更省,是现代 Transformer 的默认配置。
桥接到我们我们的抽象问题——小模型要训得稳、参数不涨、可更深更窄——和它们在大模型上解决的"深层稳定 / 归一化效率 / 门控表达力"是同一类数值优化问题。所以这整套在 LLM/ViT 上验证过的现代组件,能成套装到 3D 气象骨架上,几乎是免费的稳定性和效率红利。

7零件如何协同(一个 block 走一遍)

把六个零件串起来,一个 AttnFFN block 的完整前向就是:

  1. pre-RMSNorm(④)先把输入归一化(轻)
  2. 进注意力:QK-Norm 余弦 + 可学习温度(②)+ 加 RelPosBias3D(③),softmax 后聚合
  3. 输出乘 LayerScale(⑥,初始极小)、过 DropPath(⑥),再加回残差
  4. 又一次 pre-RMSNorm(④)→ SwiGLU 门控 FFN(⑤)→ LayerScale·DropPath → 残差

这套组合拳的合力:训得稳(QK-Norm+LayerScale)、参不涨(RMSNorm 无 β + SwiGLU 8/3d)、能更深更窄(余弦注意力+随机深度)。正是这些,才让 5.19M 的窄学生扛得住蒸馏、逼近得了教师。

对照官方量化竞赛讲义 04A–04E

这几个零件不是拍脑袋选的,正好对应官方讲义的注意力/归一化/FFN 升级专题:04A 注意力升级(QK-Norm/SwinV2 温度)、04C 归一化(RMSNorm)、04D FFN(SwiGLU)、04E SwinV2 位置编码(RelPosBias+可学习温度)。学生把这一整套现代组件成套装配到了 3D 气象骨架上。

8HIP/DCU 视角 + 本课要点

这些零件对国产 DCU(gfx936)天然友好

六个零件全是 element-wise + GEMM,没有任何奇怪算子——RMSNorm 就是一遍 reduce+乘、SwiGLU 是两个 GEMM + 逐元素乘、QK-Norm 是 normalize + 矩阵乘。 这意味着它们能被直接写成高效 HIP 核:L10 会讲学生把 RMSNorm、SwiGLU、带 QK-Norm 的 flash 注意力都做成手写核(libflashattn.so 一体化 QK-Norm+温度+bias+softmax),吃满 Matrix Core。相比教师的移位窗口 + 大 attn_mask,学生的零件为规整稠密计算而生。

本课要点(记住这 6 条)
  1. QK-Norm:q,k 单位化→余弦(幅度有界)+ 每头可学习温度 τ。治标准点积的幅度发散/softmax 饱和,可更深更窄。
  2. RelPosBias3D:Swin 式 3D 相对位置偏置查表加到注意力分数,给注意力空间位置感,相对→省参泛化好。
  3. RMSNorm:只按均方根缩放,去掉中心化和 β。比 LayerNorm 轻、显存省、精度等价,DCU 尤其受益。
  4. SwiGLU:门控 FFN,隐藏维取 8/3d→白拿门控表达力却不涨参;学生再用 mlp_ratio=2.0 继续缩。
  5. LayerScale(λ 初始 1e-5)+ DropPath:前者让残差分支慢慢长大稳深层,后者随机深度做正则。
  6. 合力 = 训得稳 + 参不涨 + 能更深更窄。对照官方讲义 04A–04E,全是 element-wise+GEMM,对 DCU 友好、可写手写核。
