L8减脂与低秩:训练时降维才是正解

W 攻到位了(96.12),回头再榨 U/V。低秩是最经典的瘦身思路,但用错方向会白掉分。这一课讲清一个反直觉的实测结论: 对训好的权重做 SVD 事后拆分 → 否定;从一开始就把模型练在低维上(减脂)→ 才是正解。关键在"权重满秩、激活低秩"这条洞察。

1回到攻 U/V:架构级再瘦身

L5–L7 把 W 攻上去了。现在回头看 U(模型大小/显存)和 V(时长)——它们已经近满,但架构级还能不能让模型更小更快、还不掉 W?这就是"低秩/减脂"要回答的。

神经网络里到处是大矩阵(注意力的 QKV、FFN 的 W1/W2)。低秩的想法很自然:如果一个大矩阵能用两个小矩阵近似(W ≈ A·B),参数就从 d² 降到 2dr(r 是秩)。问题是:该在什么时候降秩?训完再压,还是一开始就练小?——这个选择决定了成败。

2直觉做法:SVD 事后拆分权重

最直觉的低秩压缩:先正常训好模型,再对每个权重矩阵做 SVD 分解,砍掉小奇异值,把 W 换成低秩近似 W ≈ UrΣrVrᵀ。秩 r 留得越少,参数越省。

# 事后 SVD 低秩压缩(直觉做法) U, S, V = torch.svd(W) # 对训好的权重分解 W_lowrank = U[:, :r] @ diag(S[:r]) @ V[:, :r].T # 只留前 r 个奇异值 # 尝试了 r=0.7 / 0.5 / 0.35 三档(留 70%/50%/35% 的秩)

三档 SVD 压缩权重(student_svd_r0.7/0.5/0.35)都做了。结果——掉点。留得越狠掉得越多。这条路被否定了。为什么这么"合理"的做法会失败?

3为什么 SVD 事后拆分被否定

因为一个反直觉的事实:训好的权重矩阵几乎是满秩的——它的奇异值不怎么衰减,信息铺满了所有维度,没有"小奇异值"可砍。

类比:一张写满字的纸,没法"压缩空白"

SVD 压缩就像"删掉纸上的空白区域"。可训好的权重是一张写满字的纸——没有空白可删,你删的都是字。低秩压缩要有效,必须让权重本来就存在冗余。而这个冗余,得靠"从头就练小"来创造,不是事后去找。

4关键洞察:权重满秩,但激活低秩

这里有个决定方向的关键测量:权重满秩(有效秩 ≈ 0.97),但激活是低秩的(有效秩 只有 0.07–0.17)。这一高一低,指出了低秩该用在哪。

为什么这个区别是全课的分水岭

激活低秩 ≠ 权重低秩。激活低秩说明"数据只需要一个小空间",这是可以更窄的信号;但权重是满秩的,说明"模型已经把这个小空间的信息塞满了每一维",事后没法再拆。所以低秩的红利要在训练时兑现(限制维度从头学),不能在训练后硬取(SVD 砍秩)。

数学原理 · SVD 截断误差、有效秩、为什么低秩要加在训练时

SVD 截断:W = UΣVᵀ,只留前 r 个奇异值的近似误差 = 被砍掉的奇异值的平方和:

‖W − Wr‖² = Σi>r σi²　→　σ 衰减快才能小误差压缩

有效秩(把归一化奇异值当概率算熵):erank = exp(H(σ̃))。实测权重 erank ≈ 0.97·n(近满,σ 几乎不衰减,砍就掉点);激活 erank ≈ 0.1·n(低秩,能量集中在前几维)。

激活低秩说明"数据只用了小子空间",但权重满秩说明"信息已塞满每一维"→ 低秩红利只能在训练时兑现(限制维度从头学),事后 SVD 砍不动。

参考项目 · LoRA(Hu et al., 2021)+ Muon(Jordan et al., 2024)
抽象问题LoRA 假设"权重更新是低秩的",用 ΔW = BA(r≪d)训练、冻结原 W——把低秩约束加在训练过程(优化路径)而非事后权重。Muon 对 2D 权重的动量做 Newton-Schulz 正交化,让更新在各奇异方向均衡下降。
怎么变好LoRA 让大模型微调只训 ~0.1% 参数、显存暴降,成为 LLM 微调标配;Muon 在小模型/预训练上比 AdamW 收敛更快。
桥接到我们LoRA 的核心洞察"更新低秩、约束加在训练时"和我们"激活低秩→训练时降维(减脂)"是同一族思想:低秩要加在优化路径上,不是事后砍权重。减脂是"从头把维度限低",LoRA 是"把更新限低",都是训练时低秩。而 Muon 正好专治减脂后的窄 2D 权重——所以它俩是我们这条线最直接的理论/工具支撑。

5正解:训练时降维(减脂)

SVD 事后拆分(否定)

先训满,再砍秩。权重满秩→砍的都是真信息→掉点。相当于"练成了再抽掉一半肌肉"。

减脂:训练时降维(正解)

从一开始就用更窄的层训(减小 mlp_ratio / embed)。模型在低维约束下从头学,会自动把信息压进保留的维度——练成的是"精瘦"的模型,不是被抽过的。

具体到学生:减脂主要是调 FFN 的膨胀率 mlp_ratio(FFN 是参数大头)。从标准的 mlp_ratio=4 往下减到 3、2,配合窄 embed,直接把参数练下来,而不是训完再压。对应权重 student_ratio2 / ratio3。

为什么"练小"比"压小"好

同样是低秩,约束加在训练前 vs 训练后,结果天差地别:训练前限制维度,优化器会在这个约束下找最优解、把信息主动组织进有限维度;训练后砍秩,是被动破坏已经组织好的信息。前者是"戴着镣铐把舞跳好",后者是"跳完再砍掉一条腿"。

6减脂曲线甜点在哪

减脂不是越狠越好:减太少不省 U/V,减太多掉 W。要找边际拐点——再减下去 W 掉得比省的多的那个点。系统扫描 mlp_ratio 的 4/3/2 三档:

怎么判断到了甜点:用效率评估工具

不靠拍脑袋,靠一套诊断工具系统判断:有效秩(effective rank)看信息是否还铺得开、激活低秩度看容量是否还有冗余、CKA 表征相似度看减脂前后表征是否互补/塌缩、成本-收益算每减 1M 参数掉多少 W。多个信号一致指向"再减就亏"时,就是甜点。

7Muon 优化器 + 动量 0.99

减脂后的窄模型,换个优化器能训得更快更好。Muon 是 2024 年出现、在小模型/预训练上很亮眼的优化器,专门管 2D 权重矩阵。下面把它的机制、为什么有效、以及动量取值逐条讲透。

① Muon 的机制:动量 + Newton-Schulz 正交化优化器

是什么:Muon 只负责2D 权重矩阵(注意力的 QKV/输出投影、FFN 的 W₁/W₂ 这些矩阵),归一化 γ、bias、embedding 这些非 2D 参数仍交给 AdamW。它先像 SGD-momentum 一样累积动量 M(梯度的滑动平均),但更新前多做一步——把 M 做正交化再拿去更新权重:

θ ← θ − lr · Orthogonalize(M),其中正交化用 Newton-Schulz 迭代反复几次:X ← 1.5·X − 0.5·X·XᵀX

这个迭代把矩阵的所有奇异值推向 1,得到一个近似正交的矩阵(方向不变、把各方向"拉平")。

② 为什么正交化有效:各奇异方向步长均衡机制

问题:普通动量更新 M 的奇异值分布很不均——大奇异值方向"走得飞快"、小奇异值方向"几乎不动",相当于不同方向用了差别巨大的有效学习率,收敛慢且不稳。

正交化的作用:把 M 的奇异值全拉平到 ≈1,等于给每个方向都配了合适、均衡的步长 → 更新在所有方向同步、均匀地下降。直觉上,它让优化器"每个方向都照顾到",不会被少数大方向主导。这对窄模型(参数少、奇异方向少)收益尤其明显——每个方向都金贵,均衡下降不浪费。

实测:小模型下 Muon 比 AdamW 省 30–40% 训练时间,同 epoch 下 train_loss 更低(abc66 冒烟:Muon 0.232 < AdamW 0.255)。

③ 动量 0.99 是实测甜点超参

是什么:Muon 的动量系数 μ 控制 M 对历史梯度的记忆长度。把 μ 扫一遍,0.99 最优。

为什么高动量配窄模型:μ 越高,M 平均掉的历史越长、方向越稳(把单步梯度噪声抹平)。窄模型每步的梯度相对噪声更大(参数少、批内统计更抖),高动量正好帮它稳住更新方向、不被噪声带偏。student_mom99(embed96 / depths(2,4,2) / grid + Muon 动量 0.99,约 5.83M / 1.05×)就是这条线上很强的一个配置。

8HIP/DCU 视角 + 本课要点

减脂 vs 事后压缩,在 DCU 上的差别

减脂练出的是规整的窄稠密矩阵——在海光 DCU 上就是更小的规整 GEMM,直接吃满 Matrix Core、访存也少,U/V 双赢。而 SVD 事后拆分会把一个 GEMM 拆成两个小 GEMM(W→A·B),算子变多、可能更碎、还掉精度,在国产卡上不划算。结论一致:训练时把模型练小(规整窄稠密)最适配 DCU,别在推理期玩权重分解。张量分解(Tucker/TT)、剪枝同理——能训小就别事后拆。

本课要点(记住这 6 条)
  1. 低秩要用对时机:训完再压 vs 一开始练小,结果天差地别。这一课的分水岭。
  2. SVD 事后拆分被否定:训好的权重几乎满秩(有效秩 0.97),奇异值不衰减,砍秩=硬删真信息,必然掉点。
  3. 关键洞察:权重满秩(砍不动)但激活低秩(0.07–0.17)。激活低秩说明"可以更窄",但红利要在训练时兑现,不是事后砍权重。
  4. 减脂 = 训练时降维:从头用更窄的层训(主要减 mlp_ratio),模型主动把信息压进保留维度,练出"精瘦"而非"被抽"的模型。
  5. 找甜点:扫 ratio4/3/2,边际拐点≈ratio3(5.09M/1.06×)是性价比最高点;用有效秩/激活低秩/CKA/成本收益判断"再减就亏"。
  6. Muon + 动量 0.99:2D 权重正交化动量,窄模型省 30–40% 训练时间、收敛更好(mom99 约 5.83M/1.05×)。DCU 上"练小的规整窄稠密"最适配。
