L7物理先验:从软约束到架构硬约束

L5 蒸馏、L6 真值,都是"数据"的招式。这一课问一个更进阶的问题:气象有明确的物理规律,能不能用它再挤出精度? 答案是能——但注入方式决定成败。这一课讲清一个反直觉的结论:把物理写进损失(软约束)容易失败,把物理搬进架构(硬约束)才稳。

1物理先验:数据之外还能挤出的分

蒸馏和真值监督榨的是数据里的信息。但大气不是任意的高维数据——它遵守物理规律:质量/能量/水汽近似守恒、场是球面几何、有多尺度谱结构。这些规律是免费的额外先验,用好了能拿到纯数据方法拿不到的分。

问题只有一个:怎么把物理"告诉"模型?有两条路——写进损失(软约束),或搬进网络结构(硬约束)。这一课就是这两条路的对决,结论可能和你的直觉相反。

2软约束路线:把物理写进损失

最直觉的做法:再加一个损失项,惩罚模型违反物理的程度。针对学生"patch16 太糊、丢了小尺度"的毛病,一组物理软约束是这样的:

谱损失(治过平滑)

学生下采样后高频功率偏低(场太平滑)。对齐师生输出的功率谱(平面 FFT 的 log-power,或球谐角功率 C_ℓ),把丢掉的高频细节罚回来。

梯度损失 / 高频谱(治棋盘)

罚水平梯度差(治块状/棋盘伪影)、罚高波数幅度差(专补小尺度);还可高低频分离——高频对真值、低频对教师。

思路很美:直接告诉模型"你的谱不对、梯度不对,改"。但实践里,它很难稳定涨分,甚至会训崩。为什么?

3软约束为什么失败:抢梯度

软约束的本质是往总损失里再塞一个目标。而多个目标塞在一起,梯度会互相拉扯——这就是根本问题。

还有两个附加的坑
  • 量级失控:FFT 幅度动辄 1e3+,谱损失权重给 0.1 就能让总损失爆掉(实测训崩到 RMSE 675、ACC<0)。救法:log(|FFT|²) 把量级压到 O(1)、前几个 epoch warmup 慢加权、fp32 算 FFT。
  • 时机敏感:早期(还没收敛)加软约束影响小,一旦到了已收敛点,它就开始抢梯度反升 RMSE。调参窗口很窄。

即便把这些坑都填了,软约束涨分依然不稳、看数据脸色。这说明"把物理写进损失"这条路本身有结构性缺陷。

4正解:守恒硬约束层(搬进架构)

换个思路:别"建议"模型守恒,直接从结构上"保证"它守恒。做法是在输出头后加一个守恒校正层,让输出天然满足短期守恒。

物理事实:6 小时内,全球总质量/能量/水汽近似守恒——输出场的全球(纬度加权)平均,应该和输入场的全球平均基本一致。守恒校正层就把这个约束硬性焊进输出:

# maxvit3d_student_mitai.py:334-356 ConservationCorrection(后置守恒校正层) w = torch.cos(lat).clamp(min=0); w = w / w.mean() # 纬度加权(球面上高纬格点小) self.alpha_s = nn.Parameter(torch.zeros(4)) # ★每通道系数,初始 0 = 恒等 # 前向:把输出的全球均值,朝输入的全球均值 nudge 回去(守恒) surf_out = surf_out + alpha_s * ( gmean(input) - gmean(surf_out) )

5硬约束的三个关键设计

这个层看着简单,但三个设计细节让它只会涨分、不会崩:

① 硬性保证,不靠"建议"

守恒是前向结构直接算出来的(全球均值对齐),不依赖损失去"惩罚"。所以它一定满足,也不占梯度、不和 RMSE 抢方向——从根上避开了软约束的病。

② 初始恒等(alpha=0)→ resume 无损接入

alpha 初始化为 0,此时校正项 = 0,整层就是恒等映射——加上它,对已经训好的权重输出完全不变。于是可以在最好的现有权重上无损接上这层,不用从头训。

③ 训练学 alpha → 无损叠加,只涨不亏

接上后继续训,让每通道的 alpha 自己从 0 慢慢长大。由于起点是恒等(不掉分),训练只会往"守恒有帮助"的方向走——本质是一次无损叠加。

实测:接上守恒层后 RMSE 降、ACC 升

在 grid 基线(约 1.14×)上接守恒层继续训:RMSE 18.34 → 18.18、ACC 0.9833 → 0.9839(约 1.13×)。方向明确为正(该幅度含继续训数据的贡献,严格净增益需 A/B 对照——但"恒等初始化 + resume 无损反涨"这个性质本身就保证了它不会亏)。

数学原理 · 软约束(惩罚项)vs 硬约束(投影)

软约束 = 拉格朗日式惩罚:在主损失上加违反物理的惩罚项 C(θ),

minθ [ L(θ) + λ·C(θ) ]　→　∇ = ∇L + λ∇C

在 L 的极小点附近 ∇L≈0,但 ∇C≠0,优化被拉向"减小 C"却可能增大 L(RMSE)——两个梯度方向冲突,这就是软约束抢梯度的数学面目。

硬约束 = 把输出投影到"满足约束的流形"上。守恒是线性约束(全球加权均值 = 定值),对应一个投影算子 P:

output ← Proj守恒(output)　→　C ≡ 0 恒成立,不进损失、不占梯度

约束由前向结构保证,优化器完全不用为它分心——这就是硬约束稳的根本原因。

桥接到我们我们的守恒校正层就是 Beucler 思路的轻量实例——全球均值校正 = 质量守恒的线性投影,底层数学问题"把线性守恒约束投影进输出"完全一致。SFNO 则指出球面几何该用等变结构,是我们继续上分的架构方向(L7 展望)。读懂"硬约束=投影到约束流形"这个抽象,就知道物理该往架构里搬、而不是往损失里塞。

6软 vs 硬:本质是"建议"与"保证"之别

软约束 = 建议

  • 加一个损失项,惩罚违反
  • 和主损失抢梯度,方向可能冲突
  • 只是"劝",不保证真满足
  • 量级/时机敏感,调参窗口窄
  • 已收敛点容易反升 RMSE

硬约束 = 保证

  • 改网络结构,前向直接满足
  • 不占梯度,不和 RMSE 打架
  • 结构上一定满足物理
  • 初始恒等 → resume 无损接入
  • 无损叠加,只涨不亏
一句话记住

能用结构保证的,别用损失去劝。物理先验的正确打开方式是"搬进架构"而非"写进损失"——这个原则不止气象,在任何"有硬性约束可利用"的任务里都成立(守恒、对称、边界条件、单调性…)。

7更多物理路线(展望)

守恒校正层只是"物理搬进架构"的一个入口。同一思路下还有更彻底的做法,是这类模型继续上分的方向:

球面等变 / SFNO

地球是球面,用球谐变换算子(SFNO)或旋转等变结构,把球面对称性写进网络——比"当平面处理"更符合物理,极区不失真。

物理特征输入

把太阳天顶角、地形、海陆掩膜、次网格地形等物理量当额外输入通道,给模型显式先验(学生已预留 surf_in 扩展位)。

分频融合(DRIFT-Net 式)

高频走局部/block、低频走全局/谱,分频段各用最合适的算子,兼顾细节与大尺度——把"谱"从损失搬到结构里。

线性注意力 ≈ 物理 slice

原型/slice 注意力(Transolver 一类)本身可看作对物理场的低秩物理分解,既省算又贴物理结构(学生的 fpa 支路即此思路)。

8HIP/DCU 视角 + 本课要点

硬约束层在 DCU 上几乎零成本

守恒校正层只是一次纬度加权求均值 + 逐通道 axpy(out += alpha·(gmean_in − gmean_out)),全是 reduce + element-wise,在海光 DCU 上是极廉价的算子、可轻松融进推理核,对 U/V 几乎没影响。相比之下,软约束的 FFT 谱损失在训练期就很贵、还只在训练用。硬约束不但更稳,部署上也更省——这是"物理搬架构"的又一个隐性好处。

本课要点(记住这 6 条)
  1. 物理是免费先验:气象有守恒/球面/谱结构,用好了能拿纯数据拿不到的分,但注入方式决定成败。
  2. 软约束(写进损失):谱损失/梯度损失治过平滑,思路美好但会抢梯度——已收敛点反升 RMSE,还有量级失控、时机敏感的坑。
  3. 软约束的救法:log 压缩谱、warmup 慢加权、fp32 算 FFT;但即便如此涨分仍不稳,是结构性缺陷。
  4. 硬约束(搬进架构):守恒校正层在输出末端硬性拉平全球均值,结构上一定守恒、不占梯度,只调均值不动细节。
  5. 三个关键设计:硬性保证 + 初始恒等(alpha=0)resume 无损接入 + 训练学 alpha 无损叠加。实测 RMSE 降、ACC 升,且"只涨不亏"有结构保证。
  6. 原则:能用结构保证的别用损失去劝——"建议 vs 保证"。展望:SFNO 球面等变 / 物理特征输入 / 分频融合 / 物理 slice 是继续上分的方向。
