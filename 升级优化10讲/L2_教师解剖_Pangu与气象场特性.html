1为什么先解剖教师

这门课的主线是知识蒸馏——让小学生"照着大教师学"。既然要照着学,就必须先看清被照的对象:

  • 接口要对齐:学生的输入输出必须和教师逐通道一致,才能拿教师的输出当监督信号、才能用官方 result.py 评测。所以教师的 I/O 规格是学生设计的硬约束。
  • 要知道教师强在哪:Pangu 之所以准,靠的是几个关键设计(3D 注意力、Earth-specific 偏置)。学生要在小规模下逼近它,得保留精髓、换掉贵的部分。
  • 要知道气象场难在哪:百万格点、多层多变量、长程依赖——这些"难"决定了学生的骨架为什么要用 U 形下采样 + 稀疏全局注意力(下一课 L3 展开)。

2气象预报是什么问题

用一句话定义任务:给定当前时刻的全球大气三维状态,预测 6 小时后的状态。数据来自 ERA5 再分析(欧洲中期天气预报中心的历史气象场,可当作"真值")。

空间网格721 × 1440纬度 × 经度,0.25° 分辨率,全球覆盖(≈ 每 27km 一个格点)
垂直分层13 层气压面1000/925/850/700/600/500/400/300/250/200/150/100/50 hPa
预报步长+6 小时单步预报;更长时效靠自回归滚动
本质时空回归输入一个高维场 → 输出同形状的高维场,不是分类

注意最后一行:这是个场到场(field-to-field)的回归问题,输入输出都是巨大的多维张量,评价用 RMSE / ACC。这和大语言模型的"逐 token 生成"完全不同,也决定了 W(精度)对数值特别敏感——L1 里"显存优化要 bit-exact"的讲究就来自这里。

3气象场的五个"难"

为什么气象大模型必须很大?因为气象场同时踩中五个"难点"。这五点也正是学生轻量化时要小心翻越的坑。

难点① 规模巨大

721×1440 ≈ 百万格点,即使切成 patch 后仍有 52 万 token。注意力是 O(N²) 的,直接做全局注意力算不动。

难点② 多层三维

13 个气压层在垂直方向物理耦合(静力平衡、对流)。不能当成独立的 2D 图,必须 3D 建模。

难点③ 多变量异质

气压/风/温/湿量纲差异大、耦合强(地转风、湿度-温度)。学生若丢掉某变量的信息,连带的其它变量也会预报歪。

难点④ 长程依赖

气旋、急流、罗斯贝波等天气系统跨越数千公里。局部窗口看不到全局形势,必须有全局感受野。

难点⑤ 球面几何 + 物理一致性

地球是球面不是平面:极地格点密、赤道格点疏,同一个"窗口"在不同纬度覆盖的真实距离不同——所以模型不能假设"平移不变"(这正是 Pangu 用 Earth-specific 偏置的原因,见第 6 节)。 再加上各变量间有物理约束,小模型很容易预报出物理上自相矛盾的场(比如风和气压不匹配)——这是 L7 物理先验要处理的问题。

翻开教师 pangu.py 的 forward,输入张量注释写得很清楚:x: [batch, 4+3+5*13, lat, lon]。拆开这 72 个通道:

学生必须继承的硬约束

学生的 stem(输入嵌入)和 head(输出还原)直接复用官方的 PanguEmbedding / PanguRecovery 模块——这样输入输出形状与教师逐通道一致,教师输出才能当蒸馏监督、官方评测脚本才能直接打分。学生能改的是中间的骨干,不能改 I/O 接口。这是 L3 学生设计的起点。

5Pangu 架构解剖:U 形 3D-EST

Pangu 全名 3D Earth-Specific Transformer,骨架是一个 U 形的 4 层 3D Swin Transformer(编码-下采样-解码-上采样 + 跳连)。逐层看 pangu.py:

关键尺寸(patch_size=(2,4,4)、embed_dim=192):嵌入把 13 层压成 7 个层-patch(ceil(13/2))、再叠 1 个地表层 = 8;纬经 721/4≈181、1440/4=360。所以 token 数 = 8×181×360 = 521280。下采样后纬经减半到 91×180,主干 token 降到约 1/4。

6三个 "Earth-Specific" 关键设计

Pangu 比普通 Vision Transformer 准,靠的是三个专为"地球气象"定制的设计。理解它们,才知道学生要保留什么。

① 3D 窗口注意力

用 Swin 式窗口注意力(window (2,6,12),即 层×纬×经),把 O(N²) 的全局注意力降成窗口内的局部注意力,再靠移位窗口跨窗交流。3D 窗口让垂直层之间也能直接交互(捕捉静力/对流耦合)。

② Earth-Specific 位置偏置

普通 ViT 假设平移不变,但地球不是——同一窗口在极地和赤道覆盖的真实范围不同。Pangu 给注意力加了依赖绝对纬度/高度的可学习偏置,让模型知道"我在地球的哪个位置"。这是"Earth-Specific"的来历。

③ 把大气当 3D

不是把 13 层当 13 张独立的图,而是把气压层当成深度维做 3D patch 嵌入(PatchEmbed3D)。垂直方向的物理结构被显式建模,预报更符合大气动力学。

学生的取舍(L3/L4 会落地)

保留:3D 结构(仍把层当深度维)、U 形下采样、官方 stem/head 接口。 替换:把"移位窗口注意力"这种对 DCU 稠密 GEMM 不太友好、实现复杂的部分,换成局部窗口 + grid 等距稀疏全局的交替设计——既有全局感受野,又对国产卡的 GEMM 友好(L3 详解)。 简化:Earth-specific 偏置在小模型里用更轻的相对位置 + QK-Norm 近似(L4)。

数学原理 · 窗口注意力为什么能把 O(N²) 压成线性

全局注意力让每个 token 和所有 N 个 token 算相似度,复杂度 O(N²·d)。当 N=52 万时,N² 是天文数字,根本算不动。

窗口注意力把 N 个 token 切成许多小窗口(每窗 w 个 token,w≪N),注意力只在窗口内部算:

全局 O(N²·d)　⟶　窗口 O(N·w·d)　(w 固定,故线性于 N)

代价是单个窗口看不到全局→靠"移位窗口"跨窗交流补回感受野。Pangu 还给注意力加了依赖绝对纬度的位置偏置:attn = QKᵀ/√d + B(Δpos, lat)——这就是"Earth-Specific"的数学形式。

参考项目 · Swin Transformer(Liu 2021)→ Pangu-Weather(Bi et al., Nature 2023)
抽象问题高分辨率规则网格上,如何让注意力既有大感受野、又不被 O(N²) 拖垮?Swin 的答案是窗口 + 移位窗口,把视觉 Transformer 做成线性复杂度的通用骨干。
怎么变好Swin 成为 CV 的主干范式;Pangu 把它3D 化(气压层当深度维)用于气象,是首个在中期预报上超越传统数值天气预报的 AI 模型(发表于 Nature)。
桥接到我们我们和教师面对同一个抽象问题:高分辨率规则网格的全局建模。教师选了移位窗口,我们选 grid 等距稀疏(L3)——都是"O(N²)→线性"的不同解法。正因为读懂了教师窗口注意力的数学,才知道学生该继承什么(3D 结构)、换什么(移位窗口的不规则 gather 对 DCU 不友好,换成规整的 grid)。

7教师的"贵"到底贵在哪

教师权重文件 1868MB,但真参数只有 64.22M(fp32 约 257MB)。剩下 1.6GB 是什么?——是窗口注意力的注意力掩膜 / Earth-specific 偏置这些 buffer。这恰恰暴露了教师"贵"的根源不在参数,而在它复杂的注意力机制:

真参数64.22 M≈ 257MB(fp32)
权重文件1868 MB大头是 attn_mask / 偏置 buffer(约 1.6GB)
推理峰值显存12469 MB52 万 token 的注意力中间激活撑爆显存
推理时长979.9 ms深层窗口注意力 + 高分辨率卷积
这给学生的启示

教师的显存/时长瓶颈在"52 万 token × 深层窗口注意力"。所以学生要省 U(显存)和 V(时长),最有效的杠杆不是砍参数(参数才 257MB),而是: ① 更狠的下采样(让主干 token 更少)② 更便宜的全局注意力(grid 稀疏,O(N·M) 而非 O(N²))③ 推理期释放中间激活(L9 的 tiling)。这条思路贯穿后面所有优化。

8HIP/DCU 视角 + 本课要点

教师架构在国产海光 DCU(gfx936)上的落点

Pangu 的移位窗口注意力会产生大量不规则的 gather/mask 操作,在 DCU 上比规整的稠密 GEMM 更难榨满 Matrix Core(对标 NVIDIA Tensor Core)。 这就是学生选 grid 等距稀疏全局注意力 的硬件理由——它能整理成规整的稠密矩阵乘,直接吃满 rocBLAS/hipBLASLt。用 hy-smi(对标 nvidia-smi)看显存、用 rocprof/omniperf(对标 ncu)看算子占比,方法论和 CUDA 一致,只是换工具名。L10 会手写 HIP flash 核把注意力这块再压一刀。

本课要点(记住这 6 条)
  1. 任务:给定当前大气三维状态,回归出 6 小时后的场。网格 721×1440×13 层,多变量,ERA5 当真值。
  2. 五个难:规模巨大(52万 token)、多层三维耦合、多变量异质、长程依赖、球面几何+物理一致性。
  3. I/O 规格:输入 72 = 4 地表 + 3 常量掩膜 + 5×13 高空;输出 4 地表 + 5×13 高空 = 69 通道(掩膜不预测)。学生必须逐通道对齐,复用官方 stem/head。
  4. 架构:3D Earth-Specific Transformer,U 形 2-6-6-2,主干 12 块跑在下采样后的 1/4 token 上 + skip 跳连保细节。
  5. 三个精髓:3D 窗口注意力、Earth-specific 位置偏置、把大气当 3D。学生要"保结构、换贵的注意力、简化偏置"。
  6. 贵在哪:真参数才 64.22M(257MB),显存/时长瓶颈在"52万 token×深层窗口注意力"。学生省 U/V 的杠杆是更狠下采样 + 更便宜的全局注意力 + 释放激活。
