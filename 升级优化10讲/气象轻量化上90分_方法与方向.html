上 90 优先级路线

0上 90 的总账:分该花在哪

先想清楚 90 分从哪来。总分 = U(模型大小+推理显存,40)+ V(推理时长,20)+ W(预测精度,40)。三维的提分难度天差地别:

为什么这么分

U 是"越小越好"的线性分、V 被加速比的指数压平——两者一旦选了够小够快的学生 + 做了基本的部署优化,就都进了 97% 的平台区,再抠性价比极低。而 W 是气象预报的真本事,越接近教师越难、想超教师更难。所以:把 U/V 快速拿够,把主要精力和创新押在 W 上——这是上 90 的总策略。

1方向一 · 轻量骨架选型(拿 U/V 的地基)

为什么:骨架决定了 U/V 的天花板和 W 的起点

气象场是规则网格 + 强长程依赖 + 多层三维。骨架既要够小够快(U/V),又要有全局感受野去抓天气系统(W 的地基)。选错骨架,后面怎么调都费劲。核心矛盾:全局注意力 O(N²) 太贵——要找次线性又对硬件友好的全局机制。

MaxViT(block+grid)
局部窗口 + 等距稀疏全局交替,线性复杂度、对稠密 GEMM 友好。UV
Swin / SwinV2
移位窗口注意力,经典强基线;但移位 gather 对国产卡不够规整,教师 Pangu 用的就是它。
FNO / AFNO / SFNO
傅里叶神经算子,频域一次拿全局 O(N log N);SFNO 用球面调和,天然适配地球球面,是气象大热方向。
Transolver / 线性注意力骨干
物理 slice / 原型注意力把 O(N²) 降到 O(N·M),内容自适应、对稠密 GEMM 友好。
GraphCast / GNN
图神经网络,适配不规则网格 / 多分辨率二十面体;DeepMind 气象 SOTA 路线之一。
U-Net / U 形多尺度(叠加项)
不是独立骨架,而是"下采样把主干算力放低分辨率"的通用结构,任何骨架都该叠上,直接省 U/V。V
选型建议

冲 90:优先 MaxViT / SFNO / 线性注意力骨干 + U 形多尺度。要"稳妥拿分"选 MaxViT(工程成熟、DCU 友好);要"赌上限 + 物理契合"可试 SFNO(球面等变);算力紧就上线性注意力。三者都能把 token 复杂度压到次线性。

2方向二 · 降 token / 降算力(把 V 拿满)

为什么:注意力和 FFN 的成本随 token 数走,token 是最粗的旋钮

721×1440 的场即使打成 patch 也有几十万 token。token 少一半,主干便宜一大截,V 和 U 同时受益。降 token 有很多手段,可叠加使用。

大 patch
增大 patch 尺寸把 token 数降一个量级,最粗的一刀;细节靠 stem/局部注意力/skip 补回。VU
U 形下采样
主干最深的计算放在下采样后的 1/4 token 上。V
Token Merging(ToMe / ALGM)
免训练地把相似 token 合并,推理期动态降 token,即插即用。
线性 / 稀疏注意力
Performer / Linformer / Agent Attention(线性),axial / 局部窗口 / grid(稀疏)——把 O(N²) 降到 O(N) 或 O(N·M)。
频域全局(FNO 类)
FFT 一次拿全局 O(N log N),不用逐 token 两两算,是"绕过 token 复杂度"的另一条路。

3方向三 · 现代组件:让小模型训得稳、参不涨

为什么:5M 级小模型容量紧,组件选对能"白拿"稳定性和表达力

把 block 内部的归一化、注意力缩放、FFN 换成 2024–2026 的现代选择,既省参又稳训,让学生能更深更窄地逼近教师。这些几乎是"免费午餐"。

QK-Norm + 可学习温度
q,k 单位化成余弦 + 每头温度,治点积幅度发散、softmax 饱和,可更深更窄(SwinV2)。
σReparam / ReZero / DeepNorm
其它稳深层注意力/残差的方案:σReparam 谱归一、ReZero 零初始、DeepNorm 残差缩放,可替代或叠加 LayerScale。
RMSNorm
去中心化、无 β,比 LayerNorm 轻、显存省、DCU 友好(现代 LLM 标配)。
SwiGLU 门控 FFN
隐藏维取 8/3d,白拿门控表达力却不涨参;同类可选 GeGLU / ReGLU。
LayerScale + DropPath
残差分支慢启动 + 随机深度正则,稳深层、防过拟合。

4方向四 · 蒸馏范式(守住 W 的大盘)

为什么:小模型直接对真值训难收敛,蒸馏让它站在教师肩膀上

教师的软标签携带"大气各处怎么协同"的丰富结构信息,比硬标签好带得多。蒸馏先把 W 的大盘守住(逼近教师),再谈超越。蒸馏有多种信号可用,能叠加。

输出蒸馏(软标签)
直接对齐教师输出场(加权 L1)。最基础也最有效,是主干。W
特征蒸馏(FitNets)
对齐师生中间层特征,传递更细的表征;需师生维度对齐或加投影。
关系蒸馏(RKD)
对齐 batch 内样本间的距离/角度关系,补回流形结构;0 参 10 行,直接加在 L1 上。
注意力蒸馏(AT)/ DKD
对齐注意力图(AT);DKD 把蒸馏损失解耦成目标/非目标两部分单独加权。
自蒸馏 / weak-to-strong
用低质量旧学生先热身,再切真教师,加速收敛 30–50%。

5方向五 · 真值监督破天花板(攻 W 的决胜手)

为什么:纯蒸馏的天花板就是教师,想上 90 必须"超教师"

蒸馏让学生"像教师",精度永远 ≤ 教师。要涨到 90,必须让学生在关键通道反超教师——唯一的办法是引入不受教师限制的真值信号。这是精度提升空间最大的一块,也是这类赛题最值得投入的方向。

双损失(蒸馏+真值)
loss = α·教师 + (1−α)·真值。真值这一路不受教师限,让关键通道(尤其温度)有机会反超教师。W
多步 rollout 微调
GraphCast / Stormer / Aurora 的杀手锏:让模型自回归滚动 N 步再对真值算损失,直接优化长期预报技能。气象上 SOTA 标配。
通道 / 区域加权
对短板通道(低层风/湿)和区域(陆地/极地)单独加权,精准补洼地。
残差/趋势预测(tendency)
只学 6h 增量而非绝对场,任务更简单、梯度更稳,是气象预报常用先验。
不确定性 / 逆方差加权
按每通道增量方差自动调权(逆方差 ivw),让小信号(温度)梯度不被大信号(风)压制;也可用可学习的同方差不确定性权重。
一个隐蔽的坑(值得记住)

真值监督常有"共享头污染"问题:只监督部分输出(如近地面温度),会经共享参数把没监督的部分带歪(高空温度漂移)。破法:要么全量监督(全层真值),要么把输出头拆开。多任务/多输出模型都要防这个。

6方向六 · 物理先验(攻 W · 气象独有的加分项)

为什么:气象有物理规律,用好了是纯数据方法拿不到的分

大气遵守守恒律、有球面几何、有多尺度谱结构。把这些物理先验注入模型,能在数据之外再挤出精度。但注入方式很讲究——软约束容易失败,硬约束/架构级才稳。

谱损失 / 频域约束(软约束)
罚师生功率谱差,治学生"过平滑"。但有坑:谱损失和 RMSE 会抢梯度、量级易失控,要 log 压缩 + warmup 才不训崩。
守恒硬约束层(架构级)
输出后加一层纬度加权全球均值校正,硬性满足质量/能量守恒;可用恒等初始化以便在已训权重上无损接入。相比软约束更稳定。W
SFNO / 等变网络
球面调和算子、旋转等变、Clifford 层——把地球对称性写进网络结构,物理一致性更强。
物理特征输入
把太阳天顶角、地形、海陆掩膜、次网格地形等物理量当额外输入通道喂进去,给模型显式先验。
分频融合(DRIFT-Net 等)
高频走局部/block、低频走全局/谱,分频段各用最合适的算子,兼顾细节与大尺度。
关键经验:物理该"搬进架构"而非"当软损失"

一个常见经验:谱/梯度这类软约束在已收敛点容易抢梯度、反升 RMSE,较难稳定涨分且调参敏感;而把物理规律做成架构级硬约束(如恒等初始化的后置校正层)通常更稳、可无损接入。大体倾向:架构硬约束 / 物理特征输入 比谱软约束更可靠——具体仍需按数据实测。

7方向七 · 推理部署榨 U/V(不掉 W 的免费分)

为什么:U 的显存项、V 的时长项,大半靠部署期"数学等价"优化拿

这些优化不改精度(bit-exact 或数值等价),纯赚 U/V,是性价比极高的"免费分"。多个手段可叠加。

显存分块 tiling + 及时释放
高分辨率卷积沿维度分块(非重叠→bit-exact)、用完即释放中间张量,峰值显存可降三四成。U
权重量化 fp16 / INT8
fp16 存储数值等价即用;可选 INT8/FP8(PTQ/QAT/SmoothQuant)、张量分解(Tucker/TT)、剪枝进一步压。U
混合精度(对数值敏感层保高精度)
对激活/残差数值范围大的敏感层保留较高精度,避免纯低精度下的溢出/NaN,在几乎不增成本的前提下守住精度。
手写融合核 / flash
HIP flash 注意力(不物化 N×N)、融合 GEMM;通用可选 FlashAttention、TensorRT、ONNX Runtime、CUDA Graph、torch.compile。V
正确计时(synchronize)
异步算子必须同步后计时,否则低估耗时、评测不一致。合规基本功。

8方向八 · 判优与迭代方法论(别在错的方向上使劲)

为什么:90 分是一堆此消彼长的通道账,判错优就白干

攻 W 的每一招几乎都是双刃(补这里、歪那里)。判优的口径错了,会把真正涨分的模型误杀、把过拟合的模型当宝。方法论本身就是分。

以判卷/真值为准
最终只认官方判卷(或对真值的 RMSE);离线代理指标(对教师的 match、ppl 等)只作参考,不当结论。
双指标 + 逐通道诊断
同时看"对真值(技能)"和"对教师(表达力)";逐通道看谁涨谁跌,才知道下一刀砍哪。
小规模先验证再扩大
新想法先在小数据/少 epoch 冒烟,有效再上全量;省算力、快迭代。
消融 + A/B 对照
每个改动单独开关做 A/B,归因清楚"这 0.x 分是谁贡献的",避免"一起上、说不清"。

9上 90 优先级路线:先做什么、后做什么

HIP / 国产 DCU 视角(方法论硬件无关,只换工具)

冲 90 若跑海光 DCU(gfx936):骨架优先选规整稠密 GEMM友好的(grid/线性注意力 > 移位窗口);部署用 hy-smi 看显存、rocprof/omniperf 看算子,手写核走 HIP + Matrix Core(v_mmac)(对标 CUDA + Tensor Core),rocBLAS/hipBLASLt 替 cuBLAS。判优最终以 DCU 判卷为准——训练机上对教师的指标涨了不等于判卷涨。所有方法论在 NVIDIA 上同样成立,只是把工具名换回 nvidia-smi/ncu/cuBLAS。

一页话总结:气象轻量化上 90 的方法与方向
  1. 总账:U/V 容易近满(选对轻量骨架 + 部署优化),90 分胜负手全在 W,主要精力和创新押在 W。
  2. U/V 地基:轻量骨架(MaxViT/SFNO/线性注意力)+ U 形多尺度 + 大 patch/token 合并 + 现代组件(QK-Norm/RMSNorm/SwiGLU)+ fp16/量化 + 显存 tiling + 融合核。
  3. W 守盘:知识蒸馏(输出/特征/关系/自蒸馏多选),用软标签把学生抬到教师附近。
  4. W 破天花板(决胜):真值监督(双损失/多步 rollout/通道区域加权/残差/逆方差),让关键通道反超教师;当心共享头污染,要全监督或拆头。
  5. W 物理加分:守恒硬约束层(架构级,稳)> 物理特征输入 > 等变/SFNO >> 谱软约束(易失败)。物理搬进架构别当软损失。
  6. 方法论即分:判卷/真值为准、逐通道诊断、小规模先验、A/B 消融。每招都双刃,精细"补与守"才涨净分。
