## 一、模型轻量化方法

整体思路：用一个轻量学生网络 **MaxViT-3D（5.19M 参数）** 通过**知识蒸馏 + 真值双监督**逼近
官方 Pangu 教师（64.22M 参数），再叠加**推理期显存优化**与**fp16 权重存储/可选 INT8 量化**，
在不改动计时代码、不引入外部权重/数据的前提下，同时优化 U（模型大小 + 推理显存）、V（推理时长）、W（精度）。

### 1.1 知识蒸馏（轻量化主路径）

- **学生架构**：MaxViT-3D，`embed_dim=96`，`depths=(2,4,2)`，`num_heads=(6,12,6)`，`patch_size=(2,16,16)`，
  全局支路用 **grid 等距稀疏注意力**，`mlp_ratio=2.0`。U 形多尺度骨干（编码全分辨率 → 下采样 1/4 token 做主干计算 → 上采样 → 解码 + skip）。
- **注意力设计**：局部连续窗口（抓细节）与 grid 全局稀疏支路交替堆叠；采用 **QK-Norm**（q,k 先 L2 归一化再点积，余弦注意力 + 每头可学习温度，SwinV2 风格），训练更稳、可更深更窄；
  归一化用 **RMSNorm**，FFN 用 **SwiGLU 门控**，配 **LayerScale + DropPath**。
- **I/O 与教师严格一致**：输入 `[B,72,721,1440]`，输出 `surface[B,4,721,1440] + upper[B,5,13,721,1440]`；
  stem（PatchEmbed2D/3D）与 head（PatchRecovery2D/3D）**复用 OneScience 官方模块**，保证形状与教师可蒸馏、可用官方 result.py 评测。
- **深监督 / 双损失训练（DTP）**：损失 = `alpha · 蒸馏损失(对教师输出)` + `(1-alpha) · 真值损失(对 t+6h 真实场)`，
  两路均沿用官方加权 L1（地表权重 `sw` + 高空权重 `pw`，逐通道权重取自官方 config）。
  教师 = 官方 Pangu（载 model_bak.pth，全程冻结）。`alpha=0.5` 在“表达力（对教师）”与“技能（对真值）”间取平衡。
- **训练框架**（distill_scnet.py）：AdamW（lr 6e-4，betas 0.9/0.95，weight_decay 0.05）+ warmup(5) + 余弦退火 +
  梯度裁剪 + **EMA(0.999)** + **bf16 自动混精** + **梯度检查点**（省训练显存）+ 双指标早停（val_gtL1 对真值 / val_match 对教师）+ 最优检查点保存。

### 1.2 推理期显存优化（提升 U 的显存项）

DCU 上学生跨样本峰值显存从 ~923MB 压到 **548MB**，三项措施数学等价、不改 W/RMSE：

1. **SDPA off（`set_sdpa(False)`）**：本 DCU 的 SDPA 内存高效注意力回退会分配巨大工作集（实测注意力 ~579MB）；
   窗口内 token 很小（144），naive 注意力反而**省约 199MB 且更快**。
2. **mem_opt 空间分块 tiling（推理默认开，`maxvit3d_student.forward`）**：
   - stem/head 的高分辨率卷积沿纬度分块（`stride=kernel` 非重叠 → **bit-exact**，输出与不分块完全一致）；
   - stem 之后立即 `untyped_storage().resize_(0)` 释放输入张量存储（贯穿全程的最大常驻项）；
   - 编/解码器逐 block 释放中间张量。
3. **fp16 输入构造（计时区外，数学等价）**：直接以 fp16 构造输入，避免 299MB 的 fp32 输入常驻；
   autocast 本就把 conv 输入转 fp16，提前喂 fp16 与 autocast 内部转换 bit-exact（实测 stem maxdiff=0）。

### 1.3 权重存储与量化（提升 U 的模型大小项）

- **提交权重以 fp16 半精度存储**：`student.pth` 仅 **10.46MB**（去除优化器/冗余状态，仅留 `model_state_dict + cfg`）。
  推理本就走 autocast fp16，fp16 权重加载进模型后与 fp32 权重 autocast 推理**数值等价**
  （归一化空间 maxdiff≈0.008、meandiff≈3e-4，官方 15 指标 W 与 fp32 权重完全一致）。
- **可选进一步压缩（不影响本提交推理路径）**：对权重做 INT8 对称量化（逐张量 scale），文件可压至 **5.33MB**；
  量化/图优化工具（onnx 1.21.0 / onnxsim 0.6.3 / onnxconverter-common 1.16.0 / tensorly 0.9.0 / torch-pruning 1.6.1）
  均为官方约定环境自带，可在官方环境复现。**本提交为稳健起见采用 fp16 等价存储**（零精度损失、加载即用、无需反量化）。

## 二、设计思路

- **U/V/W 联合最优**：单纯压参数会掉精度（W）、单纯保精度则模型大/慢（U/V）。本方案以“**够小够快的学生 + 蒸馏对齐教师**”为主线，
  让学生在 5.19M（教师的 8.1%）规模下逼近教师，从而 U（大小+显存）、V（时长）大幅领先，W 通过蒸馏 + 真值双监督守住。
- **为什么 MaxViT-3D / grid 注意力**：气象场是规则网格、长程依赖强。grid 等距稀疏全局注意力以 O(N·M) 复杂度覆盖全局，
  对 DCU 稠密 GEMM 友好；U 形下采样把主干算力放在 1/4 token 上，兼顾感受野与算力/显存。
- **为什么蒸馏 + 真值双监督**：SCNet 环境有连续 6h 真值对，既可对齐教师表达（match），又可直接对真实未来场学习（技能），
  双路监督比单蒸馏更稳、技能更高。
- **为什么显存优化要“数学等价”**：W 评测对数值敏感，所有显存措施（分块/释放/fp16 输入）均保证 bit-exact 或差异远小于评测分辨率，
  确保“省显存不掉分”。
- **为什么计时加 synchronize**：DCU 算子异步，不同步会低估 GPU 真实耗时；按官方更新在 `model(invar)` 后、`end_time` 前
  新增 `torch.cuda.synchronize()`，使上报时长为真实同步耗时，与评测一致。

## 三、性能优化与实现

| 优化项 | 实现位置 | 效果 |
|---|---|---|
| 知识蒸馏轻量化 | distill_scnet.py / distill_train.py | 参数 64.22M → 5.19M（8.1%），时长 979.9ms → 65.7ms |
| SDPA off | maxvit3d_student.set_sdpa(False)（inference.py 调用） | 注意力工作集 −199MB，更快 |
| mem_opt 空间分块 + 及时释放 | maxvit3d_student.forward（eval 默认开） | 峰值 923MB → 548MB（bit-exact） |
| fp16 输入构造 | inference.py（计时区外） | 输入常驻 −299MB（与 autocast 等价） |
| autocast fp16 推理 | inference.py 计时区内 | DCU 半精度算力，提速 |
| fp16 权重存储 | student.pth（10.46MB） | 模型大小 17.47MB → 10.46MB（数值等价） |

实现要点（与代码一致）：
- 推理入口 `inference.py` 加载 `data/checkpoints/student.pth`，从权重内嵌 `cfg` 重建学生结构（无需外部结构文件）；
  `set_sdpa(False)` + autocast fp16；计时区严格按官方写法 + 新增 `torch.cuda.synchronize()`。
- `maxvit3d_student.forward` 在 eval 模式自动走 mem_opt 路径；需关闭可设 `model.mem_opt=False`（结果不变，仅显存更高）。

## 四、实验结果与分析（官方 15 指标口径）

测试环境：海光 DCU，ERA5 测试集逐对 6h 预报；时长/显存均为**同步口径**（`model` 前后 `torch.cuda.synchronize()` 才计时，与提交 inference.py 一致）。
W 严格按赛题第 7 条**只评 15 个气象指标**：mslp / 10m_u / 10m_v / 2m_t / geopotential_{850,700,500} /
specific_humidity_{850,700,500} / temperature_{850,700,500} / u_500 / v_500。

### 4.1 总体对比

| 项目 | 教师 Pangu | 学生 MaxViT-3D（本提交） |
|---|---|---|
| 参数量 | 64.22M | 5.19M（8.1%） |
| 权重文件 | 1868MB（model_bak.pth） | 10.46MB（fp16，student.pth） |
| 推理峰值显存 | 12469MB | 548MB |
| 推理时长（同步口径） | 979.9ms | 65.7ms（**14.9× 加速**） |
| 15 指标 RMSE 均 | 17.601 | 20.107 |
| 15 指标 ACC 均 | 0.9920 | 0.9897 |

### 4.2 得分（官方口径）

- **U = 39.01 / 40**
  - 模型大小项 = (1 − 10.46/1868) × 20 = **19.89**
  - 推理显存项 = (1 − 548/12469) × 20 = **19.12**
- **V = 19.40 / 20**　（S = 979.9/65.7 = 14.90×，V = (1 − 1/S^1.3) × 20）
- **W = 35.63 / 40**（官方 15 指标口径；对照 69 通道口径 W = 36.24）
- **总分 = U + V + W = 94.04**（官方 15 指标口径；69 通道口径为 94.65）

> 口径说明：15 指标里包含 mslp / 10m_u / 10m_v / 2m_temperature 四个**近地面**变量，
> 这正是学生相对教师退化最多的项（约 1.17–1.19×，合分 1.69–1.73 / 满分 2），
> 拉低了 15 指标均值；而 69 通道里大量高层 z/t/q/u/v 拟合更好（合分 1.8+）会抬高均值。
> 因此 **官方 15 指标口径 W=35.63、总分=94.04 为真实提交口径**，略低于 69 通道口径，文档以官方口径为准。

### 4.3 15 指标逐项（RMSE 项 + ACC 项，满分各 1，合 2）

| 指标 | 学生RMSE/教师RMSE | 合分(满2) |
|---|---|---|
| geopotential_500 | 1.07× | 1.866（最好） |
| specific_humidity_850 | 1.07× | 1.861 |
| temperature_500 | 1.08× | 1.852 |
| temperature_700 | 1.08× | 1.850 |
| specific_humidity_700 | 1.10× | 1.824 |
| geopotential_700 | 1.10× | 1.821 |
| temperature_850 | 1.12× | 1.798 |
| specific_humidity_500 | 1.11× | 1.795 |
| v_component_of_wind_500 | 1.13× | 1.776 |
| u_component_of_wind_500 | 1.15× | 1.747 |
| 2m_temperature | 1.17× | 1.734 |

分析：高层场（500/700 hPa 的 z/t/q/u/v）蒸馏对齐最好（合分 1.8+）；近地面风/气压/温度受地形与边界层影响、退化相对明显，
是后续提分的主攻方向（如近地面通道加权、地形物理先验）。当前权重在官方 15 指标口径下已达 **94.04 总分**。

## 五、程序代码模块说明

- **inference.py**：黑盒测试推理入口。读 `conf/config.yaml`、官方归一化统计与静态场，构建数据管线；
  加载 `data/checkpoints/student.pth`（fp16，从内嵌 cfg 重建结构）；`set_sdpa(False)` + fp16 输入 + autocast fp16；
  计时区严格按官方（`model(invar)` 后、`end_time` 前 `torch.cuda.synchronize()`，标注 AI4S 不可改）；
  输出 `result/output/*.npy` 与 `result/time_record.json`。
- **maxvit3d_student.py**：学生模型 MaxViT-3D 定义。含 grid/spectral/fpa 三种全局支路（默认 grid）、QK-Norm、RMSNorm、SwiGLU、
  `set_sdpa()` 开关、eval 默认开的 mem_opt 空间分块 forward（bit-exact 省显存）。stem/head 复用 OneScience 官方 PanguEmbedding/Recovery。
- **distill_scnet.py**：蒸馏训练主脚本（AdamW + warmup 余弦 + EMA + bf16 + 梯度检查点 + 双监督 + 双指标早停 + 最优 ckpt）。
- **distill_train.py**：蒸馏训练精简脚本（深监督双损失 DTP），便于快速复现训练流程。
- **train.py**：官方训练脚本（保留以便教师侧/基线对照复现）。
- **result.py**：官方评估与可视化脚本。
- **fake_data.py**：伪造 ERA5，用于无真实数据时快速跑通推理/训练流程。
- **conf/config.yaml**：数据管线配置（通道列表、归一化/静态场路径、img_size、逐通道权重）；test_ratio 为占位年份。
- **data/checkpoints/student.pth**：学生轻量权重（fp16，含 `model_state_dict + cfg`）。

## 六、编译说明

本方案为**纯 Python / PyTorch 实现，无需额外编译**。所有算子使用 PyTorch（DCU 版）自带核，
卷积/注意力/归一化均走框架内置实现；推理路径不依赖任何需要编译的自定义 C++/HIP 扩展，也不依赖量化/剪枝库即可运行。

环境依赖（官方约定环境自带）：OneScience 0.3.0 / Python 3.11 / PyTorch 2.5.1（DCU）/ numpy / h5py / tqdm。
可选进一步压缩用到的库（同属官方环境、本提交推理不依赖）：onnx 1.21.0 / onnxsim 0.6.3 / onnxconverter-common 1.16.0 / tensorly 0.9.0 / torch-pruning 1.6.1。

## 七、运行使用说明

```bash
source ../earth_env.sh                 # 加载官方环境

# 推理（黑盒测试入口）：结果 → ./result/output/，时长 → ./result/time_record.json
python inference.py

# 评估 / 可视化
python result.py

# （可选）复现蒸馏训练（与本提交权重同配置）
python distill_scnet.py --embed 96 --depths 2,4,2 --heads 6,12,6 --patch 2,16,16 \
                        --global-mode grid --mlp-ratio 2.0 --epochs 120 --alpha 0.5

# 无真实数据时先跑通流程
python fake_data.py
```

注意事项：
- 教师权重、ERA5 数据、统计量、静态场均由官方环境提供（`../onedatasets` 与官方 checkpoints），**不在本包内**。
- 不要修改计时区代码与赛题标注「不可更改」的参数。
- 如需关闭显存优化对照，设 `model.mem_opt=False`（结果不变，仅显存更高）。
